# 플레이테스트 피드백 (2026-10-09, v1 빌드)

Claude Code가 `v1\후삼국통일.exe`를 직접 실행하고 화면을 확인해서 정리한 문제점. 엔진/코드 레벨에서 크래시나 예외는 없음(Player.log 확인 완료) — 문제는 전부 **게임으로서의 경험**에 있음.

## 핵심 문제: "그냥 텍스트 덩어리"

사용자 피드백 원문: *"이런 게임은 계속 선택지와 유저가 무엇을 해야 하는지 알려주면서 사람이 운영을 계속해 나가게 해주는게 매력인데 그런것도 아무것도 없고 그냥 텍스트 덩어리야"*, *"여기서 사람이 뭘 하겠니"*

실제 화면(시나리오 선택, 메인 셸·영지 개요 탭)을 캡처해서 확인한 결과:

1. **화면의 70~90%가 빈 검은 공간.** `scenario-screen`, `.content` 등 컨테이너가 `flex-grow: 1`로 늘어나지만 내용물(카드 2~3개, 버튼 2개)은 위쪽에 작게 뭉쳐있고 나머지는 그냥 배경색. 지도도, 그림도, 레이아웃을 채우는 장식 요소도 전혀 없다.
2. **다음에 뭘 해야 하는지 알려주는 장치가 없음.** 하단 상태바에 "완산주 일대를 평정하세요." 한 줄이 전부. 목표 진행도, 추천 행동, 툴팁, 알림이 없어서 버튼 2개(영지 확대/경제·농업) 누르는 것 외엔 뭘 해야 할지 알 수 없다.
3. **콘텐츠 폭이 너무 좁다.** 시나리오 1개, 플레이 가능 인물 1명뿐이라 "선택"이라는 느낌 자체가 없음(`Assets/_Project/Scripts/Editor/GameSetup.cs`의 샘플 데이터가 최소 1세트만 만듦).
4. **탭 대부분이 플레이스홀더.** `GameUI.cs`의 `TabGroups`에 있는 "주요 관직", "전체 신하", "왕위 계승", "군사·사병", "병영·징집", "외교·책략" 전부 `BuildPlaceholderTab()`으로 "다음 작업에서 구현합니다" 문구만 뜸 — README에는 명시돼 있지만 실제로 눌러보면 꽤 허전하게 느껴짐.
5. **아트 자산이 화면에 전혀 안 보임 — 원인 특정함.** README에는 "그림 아직 없음"이라고 돼 있지만 실제로는 `Assets/_Project/Art/Sprites/`에 PNG 37개(초상화·깃발·자원 아이콘 등)가 이미 들어있다. 문제는 **메타 파일의 Texture Type이 전부 `Default`(일반 텍스처)로 잘못 임포트돼 있어서** `SpriteLinker.Run()`이 `AssetDatabase.FindAssets("t:Sprite", ...)`로 찾을 때 하나도 안 걸리고 전부 "연결 안 됨"으로 빠진다는 것. 예: `Assets/_Project/Art/Sprites/portrait_ieok.png.meta`의 `textureType: 0`, `spriteMode: 0` (확인한 `res_coin`, `banner_isung_clan`, `tier_village` 등 샘플 전부 동일 증상 — 아마 37개 전부).
   - 의도된 자동 설정 로직은 `Assets/_Project/Scripts/Editor/PixelArtImporter.cs`(`AssetPostprocessor.OnPreprocessTexture`)인데, `if (!imp.importSettingsMissing) return;` 가드 때문에 **이미 한 번 기본값으로 임포트된 파일은 다시 안 건드린다.** `.meta` 생성 시각(22:23)이 `.png` 생성 시각(22:14)보다 늦은 걸로 보아, 처음 프로젝트를 열 때(Library 없는 첫 스캔) 에디터 스크립트 컴파일이 끝나기 전에 텍스처 임포트가 먼저 돌면서 `PixelArtImporter`가 아직 등록되지 않은 상태로 기본 설정으로 찍혀버린 것으로 보임.
   - **고치는 법**: `Assets/_Project/Art/Sprites/*.png.meta` 전체를 지우고 에디터에서 강제 재임포트(`AssetDatabase.ImportAsset` with `ForceUpdate` 또는 그냥 meta 삭제 후 `Husamguk → 아트 자동 연결` 메뉴 재실행)하면 바로 해결될 가능성이 높음. 재발 방지하려면 `PixelArtImporter`가 `Sprites/` 폴더 안이면 `importSettingsMissing` 여부와 무관하게 Sprite로 강제하도록 가드를 완화하는 게 안전.

## 다음 작업 제안 (우선순위 순)

1. **"지금 뭘 할 수 있는지" 안내를 최우선으로.** 각 탭에 "추천 행동"이나 목표 체크리스트, 다음 턴 결과 요약(수확량 변화, 호족 동향 등) 같은 최소한의 피드백 루프부터.
2. **레이아웃이 화면을 실제로 채우게.** 빈 공간에 지도/지역 카드 그리드, 신하 목록 카드 등 콘텐츠 밀도를 올려서 "텍스트 덩어리"처럼 안 보이게.
3. 샘플 시나리오/인물 수를 늘려서 시작 화면에서부터 "선택하는 재미"가 있게.
4. 플레이스홀더 탭 중 최소 1~2개(호족·신하 쪽이 완산주 테마상 비중 커 보임)를 다음 패스에서 실제 구현.
5. 위의 스프라이트 임포트 버그부터 고치면(1번 작업) 체감 개선이 가장 빠를 것 — 이미 있는 그림 37장을 그냥 연결만 하면 됨.
