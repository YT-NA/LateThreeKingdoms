# 후삼국 대란: 천하통일 — 게임 기획서 (MVP, v0.1)

> 변방의 말단 호족(성주)으로 시작해 후삼국을 통일하는 한국식 역사 전략 시뮬레이션
> 삼국지(장수·전투) × 크루세이더 킹즈(가문·신하 통제) 스타일

원본 기획 의도는 [`원본 기획서`](./원본_기획서_요약.md) 참고. 이 문서는 그중 **MVP로 먼저 만들 범위**를 화면 구성과 시스템 단위로 구체화한 것.

---

## 1. 개요

| 항목 | 내용 |
|---|---|
| 장르 | 턴제(계절 단위) 역사 전략 시뮬레이션 |
| 테마 | 9세기 말~10세기 초 후삼국 시대, 한국적 정체성 |
| 시점 | 2D UI 중심 — 책상에서 창문으로 영지를 내다보는 구도 (§3 참고) |
| 엔진 | Unity 6 (2D, URP), UI Toolkit |
| 플랫폼 | PC 우선 |
| 턴 길이 | **계절 단위** (봄·여름·가을·겨울 = 1년 4턴) |

### 1.1 한 줄 컨셉
"작은 성 하나에서 시작해, 호족의 마음을 얻고 군사를 길러 천하를 통일한다."

### 1.2 디자인 기둥
1. **읽히는 정세** — 지도 한 번만 봐도 누가 누구 땅인지, 내 다음 목표가 어딘지 보인다.
2. **사람이 전략이다** — 영토보다 호족의 충성과 장수의 재능이 승부를 가른다.
3. **계절마다 결정** — 한 턴(계절)에 내정·외교·군사 중 우선순위를 고르게 만든다.

### 1.3 "한 턴만 더" — 무한한 할 일을 중독으로 만드는 원칙
문명·크루세이더 킹즈류 그랜드 전략의 핵심 기재를 이 게임의 기존 시스템에 명시적으로 건다. 새 시스템이 아니라 **이미 있는 시스템들을 어떤 리듬으로 배치할지**에 대한 설계 원칙.

- **엇박자 교차 목표**: 건설(§3.6, 2계절 소요)·연구·사신 도착·호족 밀당 제안 같은 진행 중 과제들의 완료 턴이 서로 겹치지 않고 어긋나게 배치되도록 밸런싱한다 — "이것만 보고 끄자"가 "그다음 것도 보고 가자"로 계속 이어지게.
- **혼돈에서 정돈으로**: §3.0 지도 화면의 핵심 쾌감은 "흩어진 호족 색이 내 세력 색으로 통일되는" 시각적 과정 그 자체. 호족 판도(§3.2)의 충성도 색상 전환, 거점 승격(§3.13)의 Before/After 대비가 전부 이 원칙의 구현체다.
- **포지티브 피드백 스노우볼**: 초반의 작은 투자(제철소 하나)가 몇 년 뒤 큰 승리(정예병으로 무혈 입성)로 되돌아오는 인과를 플레이어가 되짚어볼 수 있게, 이벤트 로그(§3 우측 알림)에 "그때의 선택" 참조를 남기는 것을 지향한다(구체 구현은 2차 범위).
- **선택지 3층위**: 즉각(이번 턴 부대 이동) / 중기(이번 가을 수확을 제철소 확장에 쓸지 조공에 쓸지) / 장기(10년 뒤 쿠데타를 일으킬지 망명할지, §2.3) — 화면 설계 시 이 세 층위를 UI 위계로도 구분한다(즉각=지도·출진, 중기=내정 탭들, 장기=왕위 계승·신분 전환).
- **딜레마형 선택지**: 단순 수치 버튼(+10)이 아니라 "A를 얻으려면 B를 포기"하는 트레이드오프로 만든다. 이미 세율 슬라이더(민심↓/엽전↑, §3.6), 호족 사병 밀반출(§2.3 독립성 vs 충성도), 신라 흡수 분기(§2.7 항복 수용 vs 합병 약탈)가 이 원칙을 따르고 있다 — 앞으로 추가하는 액션도 이 틀을 기본값으로 삼는다.

### 1.4 목표의 3단 구조 (Macro → Meso → Micro)
§1.3의 원칙을 실제 목표 레이어로 구체화한다. MVP는 아직 군주/호족 신분 하나(§2 MVP 범위)뿐이라 Macro는 고정이지만, §2.3 신분별 플레이가 열리면 신분마다 Macro가 갈라지는 구조로 설계해 둔다.

- **거시 목표(Macro, 신분별 최종 도달점)**: 군주 — 삼국통일·제국 개창(§6.2 MVP 승리). 지방 호족(§2.3) — 독립 공국 수립 또는 승리할 세력에 붙어 개국공신 최고위에 오르는 킹메이커. 신하·책사(§2.3) — 역성혁명으로 직접 왕좌에 오르거나, 흔들리지 않는 가문(§2.7 가문 육성)을 완성하는 세습.
- **중기 목표(Meso, 12~20턴 = 3~5년 단위 빌드업 페이즈)**: ① 영지·제철 기반 다지기(§2.9 병종 테크트리 완성) ② 호족 네트워크 구축(혼인·사성으로 방어선을 "철옹성"으로, §3.2·§3.14) ③ 거대 이벤트 대비(§2.5 발해 멸망 전 보급·외교 노선 결정, §2.8 계절 변수 대비).
- **턴 단위 소목표(Micro, "이것만 보고 끄자")**: 계절(§2.8)마다 다른 톤 — 봄엔 "징집 참고 대장간 레벨업만", 여름엔 "강 범람이니 수군 건조만", 가을엔 "수확 들어왔으니 무역상 거래만", 겨울엔 "강 얼었으니 후방 기습만". §3의 각 화면 하단 상태바(예: §3.1 영지 개요의 진행 중 건설 표시)가 이 Micro 목표를 직접 보여주는 자리다.
- **UI 구현 방향(2차 범위)**: 화면 한쪽에 신분별 가업 퀘스트 + 다음 계절까지의 체크리스트를 캘린더형으로 띄우는 **목표 다이어리**, §3.0 지도의 "회색/적색 → 내 세력 색" 전환을 과장해서 보여주는 연출, 그리고 "3년 전 조공 덕분에 오늘 귀순했습니다" 같은 **스노우볼 참조 알림**(§1.3의 피드백 루프를 실제 로그 문구로) — 전부 §9 MVP 체크리스트에는 없는 2차 범위 다음 작업.

## 2. 세계관 및 플레이 세력

(원본 기획서 2장 요약 — 기획서에 세 세력의 지형·성향이 정의되어 있음)

| 세력 | 거점 | 특성 |
|---|---|---|
| 고구려 계열 (태봉) | 철원·송악·평양 | 북방 기병 보너스, 호족 연합체 성향, 확장성 높음 |
| 백제 계열 (후백제) | 완산주·나주·청주 | 호남 평야 식량 생산력, 해상 무역, 호전적 군사력 |
| 신라 계열 (경주) | 서라벌 및 잔여 호족 | 유교·불교 명분, 중앙 집권력 회복, 방어전 유리 |

**MVP 범위**: 플레이어는 **백제 계열 완산주의 말단 성주**로 시작한다 (원본 기획서 1단계 "촌락 및 소규모 성"). 목표는 완산주 일대 호족을 복속시켜 **주(州) 단위 통일**을 이루는 것까지 — 원본 기획서의 4단계 중 1단계 완료 + 2단계 진입이 MVP의 승리 조건이다. 태봉·신라는 MVP에서는 지도 가장자리의 "다른 나라" 취급 (상호작용 없음), 2차 범위에서 본격 참전.

### 2.1 세력별 고유 메카닉 (2차 범위)
태봉·신라가 본격 참전할 때를 대비해 받은 아이디어를 세력별로 정리해 둔다. FactionDef가 세력마다 고유 시스템을 하나씩 걸 수 있도록 설계만 열어 두고, 실제 구현은 2차 범위.

- **태봉(후고구려, 궁예)** — **관심법/의심 게이지**: 군주가 신하 개개인의 "의심도"를 올려 숙청하는 리스크-리턴 메카닉. 의심도가 쌓이면 적중·피해 보정이 커지지만 과하면 조정 충성도가 무너지고 역성혁명(왕건의 정변처럼) 이벤트로 번짐. 사기 저하 없이 싸우는 **미륵 광신 보병**도 이 세력 고유 병종.
- **후백제(견훤)** — 상주 장사 기병 등 초반 돌파력 중심 보너스. 세력이 커질수록 **후계 갈등**(신검 vs 금강) 이벤트가 자동 발생해 내정 불안정·전투 페널티로 이어짐 — §5.4 왕위 계승의 "파벌 정치"를 후백제 세력에 한정해 더 거칠게 재현한 버전.
- **신라(경순왕 등)** — 군사력은 약하지만 "천년 고도"의 명분·외교 정통성으로 버티는 외교·지원형 세력. **골품제**로 6두품 이하 인재(예: 최치원)가 승진 한계에 부딪히면 타국으로 망명 — 신라 플레이는 이 개혁을, 타국 플레이는 그 인재를 스카우트하는 재미로 연결.
- **고려(왕건)** — 벽란도 해상 무역 + 수군 특화, 함선을 이용한 기습 상륙 작전(금성·나주 기습 재현).

### 2.2 역사 이벤트 소재 (2차 범위)
**원칙: 정해진 역사 재현이 아니라 "역할" 조건부 이벤트.** 플레이어가 꼭 왕건·견훤 같은 대표 군주일 필요는 없다 — 완산주의 이름 없는 말단 호족으로 시작해 전혀 다른 경로로 통일할 수도 있다(§2 MVP 범위). 그래서 아래 이벤트들은 특정 인물을 강제로 등장시키는 컷신이 아니라, **그 역사적 "역할"(공산 전투의 "위기에 몰린 군주", 고창 전투의 "마음을 정하지 못한 호족 3인방" 등)에 해당하는 조건이 현재 판에서 실제로 성립할 때만** 발동한다. 그 역할에 실존 인물이 그대로 있으면 역사와 같은 이름으로, 플레이어가 그 자리를 대신하고 있거나 역사가 이미 갈라졌다면 다른 인물·다른 결과로 나온다 — EventSystem이 이름이 아니라 **상황(조건)**을 체크하는 구조.

**연출**: 전투 전후로 "사극 담화" 팝업이 뜬다 — 배경 한 단락 + (여건이 되면) 정지 일러스트 컷신(PixelLab 재해석, §8) + 극적 선택지 + 결과 내레이션. §3.10 전투 결과 팝업의 역사 이벤트 전용 확장판.

| 전투(역할 조건) | 기믹 아이디어 |
|---|---|
| 조물성 전투 — 백중세 교착 + 인질 교환 | 일정 턴 강제 휴전 + 인질 교환. 인질이 죽으면(사고·선택) 외교가 파탄나고 복수전 이벤트로 이어짐 |
| 공산 전투 — 군주가 매복에 걸려 전사 위기 | **대역/희생**: 호위 장수가 대신 전사(신숭겸처럼) → 패배해도 "목숨 바쳐 신라를 구했다"는 명분·민심을 얻는 양면적 결과 |
| 고창 전투 — 호족들이 마음을 못 정한 접전 | **전투 중 호족 전향**: 명분·자원 조건을 채우면 중립 호족이 전투 도중 아군으로 전향해 판세가 뒤집힘 — §3.2 호족 판도와 실시간 연동 |
| 운주 전투 — 적이 진형을 갖추기 전 기습 가능 | **선제 타격**: 적의 버프·대형 준비를 무효화하는 기습 모드 |
| 일선리 전투 — 몰락한 전 군주가 반대편 선봉에 섬 | **국왕의 선봉**: 그 인물을 선봉에 세우면 적 전체 사기 붕괴(보스전/최종전 연출) |

### 2.3 신분별 플레이 (3차 범위 — 코에이 삼국지 "장수제" 방식)
MVP의 "말단 호족으로 시작"은 이미 아래 표의 **지방 호족** 신분 하나를 고정해 둔 것이다. 2차 범위(태봉·신라 참전) 다음 단계로, **시작 신분을 고를 수 있게** 여는 아이디어를 남겨 둔다 — 같은 시대를 전혀 다른 시점에서 재플레이하는 재미.

| 신분 | 주된 목표 | 핵심 메카닉 |
|---|---|---|
| 지방 호족(MVP 기준 신분) | 독립 세력화 또는 귀순 결정 | 영지 경영, 두 세력 사이 줄타기 외교(사성·관직·조공 제안 저울질), 세력이 커지면 독립/역성혁명 |
| 무관·장수 | 전공 축적, 군내 영향력 확보 | 전투 지휘, 주군이 아닌 "나"를 따르는 사병 육성, 주군 구출(§2.2 공산 전투형 희생)로 입지 상승 |
| 문관·책사 | 중앙 정치 주도 | 정적 모함, 적국 호족 포섭 계책, 도참·풍수로 민심 조작, 원하는 왕자를 밀어 후계자로 옹립(§5.4 파벌과 연동) |
| 근시·내군(궁예 조정 한정) | 생존 및 역성혁명 모의 | 의심도 관리(§2.1 관심법), 뜻 맞는 신하들과 은밀히 결탁해 정변 |

- 공통 서브시스템: **독립성 vs 충성도**(주군의 징병·세금 명령을 영지 사정을 핑계로 거절/일부만 수행), **사병·식읍**(주군이 내리는 관직·식읍에 따라 개인 사병 규모가 늘어나고, 이 사병이 훗날 배신의 전력이 됨), **정변·쿠데타**(군주 폭정 수치가 임계치를 넘으면 다른 신하들과 결탁해 폐위/추대).
- 이벤트 예시: "관심법을 피하라"(궁예 조정 신하 전용 텍스트 위기 이벤트), "안동 호족의 선택"(고창 전투 시점에 견훤·왕건 중 선택 — 내가 고른 쪽이 그 전투의 승자가 됨), "금산사 유배와 망명"(견훤 측근이 신검 편 또는 망명 호위 중 선택).

### 2.4 전설의 유물·영물 (3차 범위)
후삼국시대는 신화·풍수도참·야사가 짙게 얽혀 있어, 장수·가문에 장착하는 수집형 보물·신수 소재로 쓰기 좋다. 전부 설화 모티브 + 기믹 아이디어로, RetainerDef에 장착 슬롯을 하나 추가하는 식으로 나중에 얹을 수 있다.

- **가문 가보(무기·장비)**: 상주 흑호검(견훤 — 첫 돌격 시 무력·이동속도 폭발적 상승), 태봉 미륵금척(궁예 — 명분 상승하지만 매 라운드 의심도도 함께 오르는 리스크-리턴), 고려 현무철갑(왕건 — 치명타 1회 무효 + 아군 사기 회복), 청해진 진해창(장보고 유산 — 수군 전용, 해상 이동·파괴력 증가).
- **국가급 보물(서적·성물)**: 도선비기(풍수서 — 거점 방어·생산 비약적 상승, 천도 시 명분 제공), 만파식적(신라 — 영지 반란을 강제 진정, 적 사기 약화), 황룡사 구층목탑 사리(성물 — 공성 피해 감소 + 신라계 호족 충성도 고정).
- **계약 영물**: 삼족오/황룡(고려 — 수전·우천 시 명중률 버프), 백호/흑호(후백제 — 야간·산악 지형 페널티 무시 + 적 공포 부여), 미륵의 음파(태봉 — 적이 스킬 쓸 때 역피해 주는 "관심" 지대), 금성 지네/용 정령(장화왕후 설화 — 나주·전라 남부 호족 포섭 확률·수송 속도 상승).
- **획득 방식 3종**: ① **가보 포섭/노획** — 특정 호족을 포섭하거나 격파하면 그 가문 보물 획득. ② **탐험·제사** — 팔공산·지리산·송악산 등 명산 거점에서 탐험/제사 이벤트로 영물의 은혜(버프) 획득. ③ **전리품** — 신라 금성 점령이나 경순왕 포섭처럼 특정 세력을 꺾어야만 얻는 국가급 보물.

### 2.5 동아시아 외교 (3차 범위)
한반도 내부 다툼에 그치지 않고, 당시 실제로 얽혀 있던 외세를 변수로 끌어들인다 — 5대 10국(오월·후당 등, 해상 교역·책봉), 거란(발해를 멸망시킨 세력, 발해 유민 대광현 망명 이벤트와 연결), 일본 헤이안 조정·규슈 호족(밀무역, 신라구 해적 용병화).

- **사신·책봉·무역**: 서해 해상권을 쥔 세력(후백제·고려)이 중국에 사신을 보내 선진 문물·용병(연노병·공성 공병)·명분(관작)을 들여옴.
- **발해 유민 수용 vs 거란 교역**: 발해 멸망 이벤트에서 유민을 받으면 정예 기병 유닛·장수를 얻음. 거란과 거래하면 강력한 북방 기병을 쓸 수 있지만 명분·민심이 크게 깎이고(만부교 사건 모티브), 거란을 배척하면 명분·발해 유민 충성도가 오름 — 양자택일 트레이드오프.
- **대일 밀무역·신라구 용병화**: 규슈 호족과 밀무역으로 자금 확보, 또는 해적을 용병화해 적국 해안을 기습 교란.
- **신하 플레이(§2.3) 연계**: 주군 몰래 독자 무역로를 터서 사병 자금을 모으거나, 외국 용병으로 정변을 일으키거나, 국내 정쟁에서 패배하면 외국으로 망명했다가 재기하는 분기.
- **특수 유닛/보물 예시**: 발해 정예 뇌격기병(지형 무시 돌격), 오월 화약 공성병(성벽 파괴 특화), 거란 태조의 수라도(기병 통솔 대폭 상승), 헤이안 동경(수군 사기·해상 안개 시야).
- **구체 예시(역사 이벤트 패턴의 완성형 샘플)**: "발해 멸망(926)" 이벤트 — 1단계: 유민 수용(발해 뇌격기병 획득, 거란 적대, 명분↑) vs 거부(거란 우호 유지, 발해계 호족 충성도↓, 유민이 도적떼로 변함) 분기. 수용 시 2단계로 거란 사신 방문 이벤트가 이어져 "만부교 사건"(사신 억류·낙타 처형 — 전국 호족 포섭 확률↑, 거란 전쟁 확정, 보물 획득) vs 화친(거란 용병 해금, 호족 충성도 폭락) 재분기. 신하/호족 플레이(§2.3)는 주군 몰래 거란과 밀무역하는 제3의 선택지도 가짐. 이런 **"상황 연출 담화 → 선택지 → 분기별 효과 → 후속 이벤트"** 체인 구조를 다른 역사 이벤트(§2.2)에도 그대로 적용한다. 실제 구현은 분기형 데이터(JSON/ScriptableObject)로 EventSystem이 해석하는 형태— 2차~3차 범위.

### 2.6 지역별 특산품·고유 유닛·인물 배치 (전국 규모, 2차~3차 범위)
ProvinceDef가 전국 규모(§3.0의 "규모가 단계별로 달라진다")로 확장되면, 지역마다 **특산 자원 보너스 + 그 지역에서만 뽑을 수 있는 고유 유닛 + 등용 가능 인물**을 갖는다는 설계. 완산주 MVP 범위를 넘는 자료라 요지만 남긴다.

- **패턴**: 송악(왕기·철갑기병·왕건 일파), 철원(곡창·광신 법승·궁예 일파), 완산주(호남 쌀·정예기병·견훤 일파), 나주(해상 소금·수전부대·장화왕후), 금성/경주(불교 성물·화랑 시위대·경순왕), 고창/안동(산악 방어·호족 사병대·안동 3태사), 상주(군마·돌격기병·아자개), 발해/거란·오월·일본 등 외세 거점도 각자 특산 자원+용병 유닛(§2.5)을 가짐.
- **연계 기믹**: 두 지역 특산품을 함께 보유하면 상위 유닛/효과가 해금되는 "특산품 조합 테크트리"(예: 철원 철광 + 완산주 철제무기 → 중장 갑옷 병과), 점령한 지역을 신하에게 **식읍으로 하사**하면 그 지역 고유 유닛 생산비 할인 + 그 신하 개인 사병 증가.
- 완산주 로컬 MVP는 이 중 **완산주 자신의 특산품(호남 쌀 → 석 생산 보너스) 하나만** 먼저 반영해도 충분 — 나머지 지역은 §3.0이 전국 지도로 확장될 때 ProvinceDef 데이터만 채우면 되는 구조.

### 2.7 신라 흡수·천도, 계절 재해, 야사 이벤트, 가문 육성 (3차 범위)

- **신라 흡수 분기**: 신라를 꺾거나 항복을 받을 때 **항복 수용**(신라 인재·명분 자원 흡수, 대신 백제·고구려계 호족 반발↑) vs **합병·약탈**(금성 보물 싹쓸이, 대신 전국 신라계 호족 충성도 붕괴·반란) 양자택일 — §5.4 파벌 정치와 같은 트레이드오프 구조.
- **천도(수도 이전)**: 완산주 외에 송악·철원·평양(서경)·나주·경주 등으로 수도를 옮기면 그 지역 특산(§2.6)에 맞는 국정 버프(예: 서경 천도 → 북방 무역·기병 강화)를 얻는 대신 천도 비용 발생. 플레이어의 거점 등급(§6.1) 체계와 연결 — 새 수도는 즉시 경(京)급 취급.
- **야사 기반 특수 퀘스트**: 가문·신분에 따라 다른 탐험 이벤트 — 견훤 가문의 "지렁이 설화"(동굴 탐험 성공 시 체력·무력 폭증 패시브), 왕건 가문의 "용녀 설화"(서해 탐험 성공 시 수전 기상 조작 스킬), 궁예 신분의 "관심법 연마"(반대파 숙청 가능하지만 신하 이탈율 급증) — §2.4 전설 유물과 같은 결의 콘텐츠.
- **가문(문중) 육성**: 혼인(§3.14)으로 태어난 자식은 양쪽 가문의 특수 병과·스탯을 상속(예: 기병 가문 + 산악 호족 가문 결합 → 산악 기병 특화 후계자). 가문마다 가보(§2.4)를 대대로 전승해 세대가 지나도 영향력을 유지 — RetainerDef에 parentIds 두 개(모계·부계)를 추가하면 스탯 상속 계산이 가능해지는 구조.

### 2.8 계절별 전략 루프 (3차 범위 — §4 핵심 루프의 확장판)
MVP는 계절을 "턴 카운터"로만 쓰지만(§4), 장기적으로는 봄·여름·가을·겨울마다 내정·전술 변수가 달라지는 **엇박자 리듬**(§1.3)으로 키운다. §5.7 민심 관리의 "재난 상태"가 이 계절표의 한 항목이 되는 구조.

| 계절 | 내정 영향 | 전술 영향 | 전용 카드(예) |
|---|---|---|---|
| 봄 | 농번기 페널티 — 봄에 징병·부역을 벌이면 민심·가을 수확량↓ | 봄가뭄 화공 피해 2배, 황사로 시야·궁병 명중률↓ | [춘경 장려] 수확 +30%, 이번 턴 징집 불가 |
| 여름 | 보급 이동 속도 −50%, 식량 부패율↑ | 강 범람으로 도하 불가(수군만 공격 가능), 전염병·중장갑 유닛 기력 소모↑ | [수계 공작] 장마철 제방을 터뜨려 적 성벽 방어력 무력화 |
| 가을 | 대수확(연간 군량 입금), 적지 "추수 약탈"로 적 군량을 뺏어올 수 있음 | 보급 풍족 — 대규모 원정(공산·고창형 전투)의 적기, 기병 이동·첫돌격 피해↑ | [추수 약탈] 점령 없이 적 영지 군량 50% 약탈 |
| 겨울 | 군량 소비 1.5배, 동사 방지로 목재 소모 | 강 결빙으로 기병이 강 건너 배후 기습 가능, 폭설 시 행군 매우 느려지고 매턴 동상 피해 | [빙판 강행군] 언 강으로 적 보급로·후방 거점 기습 |

- 호족 플레이(§2.3) 연계: 주군이 봄 농번기에 원정을 명령하면 "농사를 지어야 한다"며 거부해 민심을 얻거나, 몰래 적지로 추수 약탈을 나가 사병 군량을 챙기는 식의 독립성 vs 충성도 선택(§2.7)으로 이어진다.

### 2.9 철기 병종 테크트리 (3차 범위)
후삼국은 제철 기술이 이미 성숙한 시대라는 고증을 §3.9 병영·징집의 병종 업그레이드 트리로 구체화한다. MVP의 4병종(보병/창병/궁병/기병, §3.9)은 이 트리의 1단계에 해당 — 나머지는 §5.3 관직·연구 시스템이 확장될 때(2차 범위 이후) 건물/연구로 해금.

- **보병계**: 보병 → 찰갑 중장보병(원거리 저항력↑) → 세력 특화(후백제 도끼파쇄병: 방패·갑옷 파괴 / 고려 장창방패부대: 기병 돌격 무력화).
- **기병계**: 경기병 → 중장기병(찰마갑, 돌파력↑) → 세력 특화(고려·태봉 철갑기병: 정면 돌파 / 후백제 상주 정예기병: 측면·후방 속도전 / §2.5의 발해 뇌격기병: 발해 유민 수용 시 해금되는 최상위 충격 기병).
- **원거리·공성계**: 궁병 → 쇠뇌(강쇠) 부대(사거리·관통력↑) → 화약 발석차(오월 무역+제철 테크 완료 시 해금, 성벽 파괴 특화).
- **호족/신하 플레이 연계(§2.3)**: 철광석 특산지(철원·충주·완산주 등, §2.6)를 영지로 확보하면 독자 제철 라인 보유 → 주군 몰래 사병을 밀무장시키거나, 중국·일본 밀무역으로 주군보다 먼저 상위 테크를 확보해 협상 카드로 쓸 수 있음.

### 2.10 3대 캠페인 45막 구조 (3차 범위 — 스크립트 시나리오 모드)
§3.18 시나리오 선택에 MVP의 "자유 플레이"와 별도로 추가할 수 있는 **완전 스크립트 캠페인**. 세력(고려·후백제·신라)마다 15막씩 총 45막, 각 세력은 전반부(1~5)·중반부(6~10)·후반부(11~15) 3단 구성 — §1.4 Macro/Meso/Micro 구조의 "3차 범위용 완성형 샘플"에 해당.

| 캠페인 | 전반부(1~5막) | 중반부(6~10막) | 후반부(11~15막) |
|---|---|---|---|
| 1장 고려 — 개창과 대통합 | **송악 개창기**: 궁예 폭정을 피해 왕건이 패서 호족과 결탁해 기반을 다짐. 특수 기믹: 관심법 의심도 관리 + 초기 호족 충성도 유지 | **위기와 전환점**: 공산 전투 대패 → 신숭겸 희생으로 탈출, 고창 전투로 안동 호족을 포섭해 주도권 획득. 특수 기믹: 대역 희생 시스템 + 안동 호족 중립 전향 | **대통합과 외세 대처**: 발해 유민 수용, 만부교 거란 사신 배척, 견훤 귀순, 일선리 총력전. 특수 기믹: 발해 뇌격기병 편성 + 사기 붕괴 연출 |
| 2장 후백제 — 패도의 정점과 몰락 | **완산주 건국**: 견훤이 상주에서 기의해 전주(완산주)를 도읍 삼고 서해 해상권 장악, 오월국 무역. 특수 기믹: 상주 기병 돌격력 극대화 + 해상 무역 자원 수급 | **금성 진격과 정점**: 신라 금성 침공·경애왕 격파로 전성기, 그러나 고창 전투에서 고려·안동 연합에 첫 대패. 특수 기믹: 약탈 경제 + 안동 호족 이탈 방지 디펜스 | **금산사 유배와 몰락**: 아들 신검·능환의 반란으로 금산사에 유폐, 탈출해 숙적 왕건에게 망명. 특수 기믹: 후계자 갈등 게이지 + 금산사 탈출 잠입 루트 |
| 3장 신라 — 천년 고도의 생존과 종착 | **풍전등화의 경주**: 후백제·후고구려 양쪽 압박 속 화랑 시위대와 천년 유산으로 수도 방어선 구축. 특수 기믹: 수도 방어전 보너스 + 명분 자원 활용 | **외교적 이간질**: 군사력 대신 외교 공작·만파식적의 명분으로 고려·후백제가 서로 싸우게 유도. 특수 기믹: 양국 이간질 외교 커맨드 + 비밀 밀서 발송 | **경순왕의 대국적 결단**: 백성 고통을 막기 위해 왕건에게 평화 양위(귀부). 특수 기믹: 백성 민심 최대치 유지 + 평화 양위 이벤트 |

**하이라이트 막 예시** (세력별 3개씩, 맵·상황·도전과제):
- **고려** — 3막 "송악의 비일(非日)"(철원 수도·궁예 궁궐, 궁예 의심도 한계 → 관심법 심판을 피해 홍유·배현경과 밀모해 쿠데타 성공) · 7막 "팔공산의 눈물"(대구 공산 협곡, 견훤 매복에 본대 고립 → 신숭겸을 미끼로 왕건을 제한 턴 내 탈출) · 15막 "일선리의 마지막 징"(구미 낙동강 일선리 평야, 신검군과 총력전 → 견훤을 선봉에 세워 적 사기를 0으로 떨어뜨려 무혈 항복).
- **후백제** — 4막 "나주 해상 장악전"(영산강·나주 앞바다, 왕건 세력권 나주를 수군으로 협공 → 능창의 수군으로 해상 보급선 차단·항구 점령) · 8막 "금성 포위 공략"(신라 수도 경주, 신라 방어선 돌파 → 제한 시간 내 왕궁 압박해 경애왕 항복 선언) · 13막 "금산사의 감옥"(김제 금산사, 신검파에 유폐 → 충성스러운 부하들의 도움으로 경비를 따돌리고 탈출로 확보).
- **신라** — 2막 "포석정의 비극 방어전"(경주 포석정·야외 행궁, 후백제군 기습 침공 → 화랑 시위대와 왕실 호위대로 막아내고 퇴로 확보) · 9막 "양대 거대 세력의 이간계"(외교 정무당·밀실, 고려·후백제가 신라를 두고 대립 → 최치원의 계책으로 양 진영 불신을 조장해 군사 충돌 유발) · 15막 "송악으로의 평화 양위"(경주 금성 대궐·송악 국경, 더 이상 전쟁을 지속할 수 없는 국가적 한계 → 백성 반발을 잠재우고 만파식적을 봉인한 채 왕건에게 평화롭게 나라를 넘김).

- 캠페인 모드는 §2.2 역사 이벤트 5종·§2.5 발해/거란 이벤트·§2.1 세력별 고유 메카닉을 **고정된 순서로 엮은 상위 레이어**다. 즉 새 시스템을 더 만드는 게 아니라, 이미 설계된 조각들을 정해진 45개 지점에 배치하는 콘텐츠 작업에 가깝다 — 그래서 자유 플레이(MVP~2차 범위) 시스템이 먼저 갖춰진 뒤에야 의미가 생기는 3차 범위.

## 3. 화면 구성 (MVP)

MVP의 모든 화면은 **좌측 탭 내비게이션 + 중앙 장면 + 우측 두루마리 알림 + 하단 상태/액션바**라는 하나의 틀(셸)을 공유한다. 틀 안의 "중앙 장면"만 탭에 따라 바뀐다. (아래 초안 이미지가 이 틀의 기준.) MVP 1차 구현(§GameUI.cs)은 이 틀을 단순화한 버전 — 자원 row·탭 rail·단일 알림 패널만 있고, 아래 §3.19의 "지휘 본부" 고도화는 2차 범위.

### 3.19 지휘 본부 고도화 — 상단바·좌측 피드·우측 통제탑 (2차 범위)
§1.3·§1.4의 "엇박자 목표·정돈감"을 실제 UI로 구현하는 설계. 지금의 단순한 상단 자원 row·정적 알림 패널을 아래처럼 키운다.

- **상단 글로벌 바**: 국호/가문명 — 국고 — 군량 — 명분 — 계절·연도. 자원이 부족해지면 해당 아이콘이 경고색으로 바뀌고, 호버 시 "겨울 대비 군량 15% 부족" 같은 해결 가이드 툴팁(시장 열기·조공 요구 버튼으로 바로 연결).
- **좌측 "오늘의 할 일" 피드**: 기존 우측 알림 두루마리를 장문 로그가 아니라 **우선순위 카드 3슬롯**으로 재구성 — 🔴 긴급 현안(딜레마 선택, 해결 전엔 턴 종료 불가), 🟡 내정 빌드업(건설·연구 완료/다음 선택 유도), 🟢 외교·호족 동향(충성도 하락 등 + 추천 액션). 카드 클릭 시 해당 화면으로 바로 이동.
- **우측 하단 "한 턴 더" 통제탑**: 계절 시계(봄→여름→가을→겨울 순환, "3턴 뒤 겨울 한파" 카운트다운), 대기 중인 부대·장수가 있으면 턴 종료 버튼 위에 경고(클릭 시 그 부대로 시점 이동), 그리고 큼직한 **턴 종료** 버튼(단축키 Space).
- **지도 색상 모드**: 버튼 하나로 [세력 판도] / [호족 충성도 — 위험 빨강·안전 초록] / [경제·특산품] / [기후·지형] 필터 전환. 강 범람·결빙 같은 계절 효과(§2.8)는 지도 위 동적 마커(물결·얼음)로 즉시 반영.

### 3.20 초반 10턴 온보딩 (2차 범위)
림월드·문명류의 "작고 명확한 성취 연속" 패턴을 계절 구조(§2.8)에 맞춰 4단계로 설계. 강제 가이드는 10턴에서 풀리고 이후 자유 플레이.

| 단계 | 턴 | 배우는 것 |
|---|---|---|
| 1. 봄의 기원 | 1~3 | 알림 피드로 위기 인지(민심 불안 → 구휼미), 첫 건설(제철소), 턴 종료·계절 순환 |
| 2. 여름의 시험 | 4~6 | 장마 범람으로 이동력 제한 체감, 첫 호족 혼인 딜레마, 제철소 완공 → 병종 업그레이드로 스노우볼 첫 체감 |
| 3. 가을의 진군 | 7~9 | 대수확으로 원정 자금 확보, 첫 소규모 전쟁, 고창형 "호족 전향" 이벤트로 무혈 영지 확장 체험 |
| 4. 겨울의 시작 | 10 | 강 결빙 연출과 함께 발해 멸망·거란 사신 같은 대형 역사 이벤트(§2.2, §2.5) 돌입 — 여기서 튜토리얼 해제, 완전한 자유도로 전환 |

### 3.21 책사 힌트 시스템 (2차 범위)
§3.20 튜토리얼이 끝난 뒤에도 플레이어를 돕는 상시 조력자. 강제 설명이 아니라 "지금 가장 이득 되는 다음 수"를 제안하는 형태.
- 신분(§2.3)에 따라 페르소나가 달라짐: 군주=수석 책사(국가 대계·민심), 호족=가문 집사(실리·뒷거래), 신하=야심 찬 동반자(세력 불리기·쿠데타 타이밍).
- **상황 진단**: 군량 부족·적에 포위·턴을 오래 흘려보냄 같은 상태를 감지해 진단 대사 + **즉시 실행 버튼**(예: "인근 호족에 식량 지원 요청" 클릭 시 §3.2로 바로 이동)을 같이 제시.
- **선제 제안**: 당장의 위기가 아니라 다음 몇 턴의 빌드업 방향(§1.4 Meso 목표)을 미리 짚어줌.
- **무모한 선택 경고**: 전력 차가 큰 상대에 선전포고하려 하면 "공산 전투 꼴 난다"는 식으로 정색 경고 — 그래도 강행은 가능(결정은 플레이어 몫).
- **신뢰도 성장**: 조언을 잘 따르면 책사가 승진해 더 고급 정보(적국 내부 음모 등) 제공, 조언을 계속 무시·폭정을 일삼으면 책사가 이탈하거나 적국에 밀서를 보내는 배신 이벤트로 발전 가능.

- 각 턴은 "작은 알림 → 짧은 선택 → 즉각 피드백"의 반복이라 §1.3 "엇박자 교차 목표"를 가장 압축적으로 보여주는 구간 — 실제 구현 시 이 표를 그대로 스크립트 이벤트 시퀀스로 옮기면 된다.

### 3.0 지도 화면 (MapScreen)
"출진" 레퍼런스로 시각 형태가 확정됐다 — 추상적인 점+선 그래프가 아니라, **일러스트풍 3D 지형 지도**(산맥·강·구름 음영) 위에 성/도시를 입체 아이콘으로 꽂고, 세력 영토를 반투명 색으로 칠해 경계선을 그린다(고려=파랑, 후백제=빨강, 신라=노랑 — 기존 3색 체계와 합치). 진군 중인 부대는 지도 위 화살표 애니메이션으로 표시.
- 내 지역 클릭 → 영지 개요(3.1)로 진입. 적/미복속 지역 클릭 → 요약 정보 + **출진 정보 카드**(좌하단, 선택한 군단의 지휘 장수·총 병력·병종 구성 표시) + **출진** 버튼.
- 출진은 즉시 전투가 아니라 "행군 → 도착 시 전투" 2단계 (지도에서 화살표로 행군이 보이고, 도착하면 §3.10 전투 결과로 이어짐).
- 상단에 같은 자원바 + 날짜, 하단에 "다음 턴" 버튼.
- **규모가 단계별로 달라진다**: MVP는 완산주 + 인접 호족 지역 8~10곳, 병력도 호족 사병 수백~수천 단위. 반면 레퍼런스 이미지는 고려·후백제·신라 세 나라가 전국 단위로 맞붙는 후반부(수만 병력, "군단" 단위 편성)를 보여준다 — 같은 ProvinceDef 그래프·BattleSystem을 **지역 수와 병력 규모만 키워서** 이 단계까지 확장하는 것이 목표이지, 후반부에 다른 시스템을 새로 만드는 게 아니다. 2차 범위에서 이 전국 지도로 전환.
- MVP 지도 범위: 완산주 + 인접 호족 지역 8~10곳 (완주, 전주 인근 촌락들, 청주 방면 접경지 1~2곳 포함).

### 3.1 영지 개요 (탭 1 — 기본 진입 화면)
- 중앙: 영지를 창문 밖으로 내다보는 일러스트 장면 (성·전답·저자거리).
- 하단 상태바: 진행 중인 건설/프로젝트 + 남은 턴.
- 빠른 액션 3개: **영지 확대**(지도로 돌아가 인접 지역 선택), **징병 실행**(병영·징집 탭 단축), **세금 징수**(경제·농업 탭 단축).

**좌측 탭 구조 확정**: 와이어프레임처럼 화면마다 평평한 탭을 하나씩 늘리지 않고, **상위 탭 5개 + 서브탭**으로 묶는다.

| 상위 탭 | 서브탭 |
|---|---|
| 영지 | 영지 개요(§3.1, 기본) · 경제·농업(§3.6) |
| 호족·신하 | 호족 판도(§3.2, 기본) · 주요 관직(§3.3) · 전체 소속 신하(§3.5) · 왕위 계승 및 후계자(§3.4) |
| 군사 | 군사·사병(§3.7, 기본) · 병영·징집(§3.9) |
| 외교 | 외교·책략(§3.8) |
| (지도) | 좌측 탭이 아니라 상단 버튼으로 전환하는 별도 화면(§3.0) |

혼사 결정(§3.14)·자식 교육(§3.15)·민심 관리(§3.16)·거점 승격(§3.13)·전투 결과(§3.10)·출진 부대 편성(§3.11)은 탭이 아니라 위 화면들에서 버튼으로 여는 **모달**이므로 좌측 탭 수에 들어가지 않는다. 아래는 이 구조를 전제로 탭 순서보다 **내용** 기준으로 정리한다.

### 3.2 호족 판도 (탭: 호족·신하)
지도 + 인물 카드 2단 구성:
- **좌: 호족 판도 지도** — 완산주 일대를 충성도 기준 3색(초록 Loyal / 노랑 Neutral / 빨강 Rebel Risk)으로 칠한 지역 지도. 각 지역 위치에 해당 호족의 초상화 마커 + 이름표(지역+인물명)가 꽂혀 있다. 마커를 클릭해 호족을 선택.
  - 예시 인물(원본 기획서 세계관의 실존 호족을 샘플 데이터로 사용): 나주 호족 김총, 철원 호족 궁예, 상주 호족 아자개, 명주 호족 김순식 등. 완산주의 견훤은 MVP 시작 시점에는 **플레이어 본인**(말단 호족)이므로 지도에 등장하지 않음 — 2차 범위에서 다른 세력 플레이 시 등장.
- **우: 선택한 호족 상세 카드** — 초상화, 이름, 충성도 %(색상 라벨 동반: 예 "15% (Red)"), 보유 병력 수, **주요 불만**(충성도가 낮은 이유를 한 줄로 — 예: "중앙군 파견 반대") 텍스트.
- 하단 액션바(선택한 호족 대상): **정략결혼 제안**(§3.14 혼사 결정 화면을 염 — 충성도 고정 + 이탈 불가, 되돌릴 수 없음), **사성**(賜姓 — 지배 가문의 성씨를 하사해 의제 가족으로 편입. 권위 소비, 혼인보다 가볍게 충성도 +N 및 이탈 확률 감소 — 역사 속 왕건의 호족 포섭책), **인질 요구**(충성도 상한↑ 대신 호족 반감 누적), **호족 회유**(엽전 소비, 충성도 +N, 반복 가능), **숙청 명령**(무력 제거 — 충성도 극히 낮고 반란 임박한 호족을 선제 토벌, 병력 손실 리스크 + 명분/권위 소비).
- 우측 알림 두루마리에 호족 관련 사건이 함께 뜬다 (예: "OO 호족의 조세 거부", "OO 호족의 혼인 동맹 제안", "OO 호족의 중립 유지").

### 3.3 주요 관직 (내각)
중앙 조정의 핵심 보직 3개를 카드로 나열:

| 관직 | 분야 | 효과 |
|---|---|---|
| 대상서 | 행정 총괄 | 내정 효율(생산/건설 속도) 보너스 |
| 대장군 | 군사 총괄 | 중앙군 훈련 속도 보너스 |
| 내사령 | 외교·책략 | 외교 성공률 보너스 |

- 각 카드: 임명자 초상화 + 이름 + 출신(호족 연고 또는 유학자 등 배경), 효과 수치, 충성도, **임명 변경** 버튼(미임명/공석도 가능 — 효과 없음).
- 우측 두루마리 "조정 칙령 및 보고": **정무 보고**(현재 임명의 영향을 서술형으로 알려줌 — 긍정 효과와 함께 "지나친 권력 집중을 경계해야 합니다" 같은 리스크 경고도 포함), **인사 제안**(예: "나주 호족 김총의 자제를 중앙 관직에 등용하여 결속을 다질 것을 권장" — 호족을 중앙으로 끌어들여 충성도를 관리하는 수단을 알려주는 훅. §3.2의 호족 충성도 시스템과 직접 연결).
- 하단 버튼: **전체 신하 명부**(§3.5로 이동), **파면 및 유배**(선택된 관직자 해임 + 처벌 — 충성도·권위에 영향, 해당 호족과의 관계 악화 리스크).
- 예시 인물(실존 고려 개국공신을 샘플 데이터로 사용): 박지윤(청주 호족, 내정 효율 +15% / 충성도 85%), 유금필(평주 호족, 중앙군 훈련 속도 +20%), 최응(신라 유학자, 외교 성공률 +25%).

### 3.4 왕위 계승 및 후계자 — **게임의 핵심 시스템**
원칙은 **장자 승계**지만, 고정이 아니라 **명분 점수(Legitimacy Score) 경쟁**으로 풀어낸다. 후계자 관리를 잘하는 것 자체가 게임의 묘미가 되도록 설계한다.

- **후계자 카드**: 왕자/대군마다 하나씩 — 초상화, 이름(+출생 순서: 장자/2황자 등), **지지도 %**(조정 파벌의 실제 지지 비율), **명분 점수**(장자 보너스 + 능력·공적 가감으로 산출되는 계승 서열의 실질 기준), 능력/기량 요약(무력·지력 등 특기), 지지 호족 목록.
  - 장자는 기본적으로 명분 점수에 **적통 장자 보너스**가 붙어 유리하게 시작한다.
  - 하지만 장자가 무능하거나 실정을 거듭하면 점수가 깎이고, 능력이 뛰어나거나 공적을 세운 차남·삼남은 점수가 오른다 — **가장 높은 명분 점수를 가진 쪽이 계승자**가 된다(장자 고정이 아님).
  - "지지도 %"는 명분 점수와는 별개로, 조정 신하·호족들이 실제로 누구를 지지하는지의 집계치. 명분 점수가 결과를 정하지만, 지지도가 낮은 채로 계승하면 뒤따르는 파벌 문제(아래)가 더 커진다.
- **카드 버튼**: 1후계자(현재 1위)는 **태자 책봉 확정**(공식화 — 명분 점수에 고정 보너스 추가), 그 외 후계자는 **후계자 지지 선언**(플레이어가 권위를 들여 특정 후계자를 공개 지지, 그의 지지도·명분 상승).
- **우측 두루마리 "조정 파벌 판도"**: 신하·호족들이 어느 후계자를 왜 지지하는지 묶어서 보여줌 (예: "군부 파벌 — 1후계자 전폭 지지, 국경 수비에 유리" / "문신 및 지방 호족 파벌 — 2후계자의 내정 능력을 높이 사며 정권 교체를 은근히 기대"). §3.3의 관직자·§3.5의 신하들이 자동으로 이 파벌에 속한다.
- **하단 액션**: **후계자 교육**(§3.15 자식 교육 화면을 염 — 능력치가 오르면 명분 점수도 서서히 오름), **폐위 및 유배**(후계자 자격 박탈 — 그 파벌의 반감 급증, 강경책).

**승계가 실제로 일어나면** (군주 사망/양위 — 2차 범위의 수명 시스템 또는 플레이어의 "양위" 선택으로 트리거):
1. 그 시점 **명분 점수 최고자**가 다음 군주가 되어 **왕실 금고(엽전 일부)와 중앙군을 그대로 물려받는다.**
2. 낙선한 후계자를 지지하던 파벌(신하·호족)을 **처분(파면·숙청)하려면 새 군주의 세력(중앙군 규모·권위)이 충분해야** 가능하다.
3. 세력이 부족하면 처분하지 못하고, 그 파벌은 조정 안에 **그대로 남아 정치를 시작**한다 — 정책에 반대하거나 충성도에 지속적으로 악영향을 준다.
4. 방치하면 그 파벌이 **다른 왕족(낙선 후계자 등)을 중심으로 결집**해 반란·내전으로 번질 수 있다.
5. 즉 승계 이후에도 플레이어는 §3.2(호족 회유/숙청)·§3.3(관직 임명)의 도구를 똑같이 써서 이 파벌들을 계속 "잘 연결"해 나가야 한다 — 왕위 계승은 한 번의 이벤트가 아니라 그 이후 조정 정치의 시작점이다.

**MVP 범위**: 군주 수명·자연사(§5.9)를 넣기로 했으므로 완산주 통일까지의 플레이 길이 안에 **계승이 실제로 한 번쯤 일어날 수 있다**. 후계자 목록·명분 점수·지지도 계산, 태자 책봉/지지 선언/후계자 교육/폐위 UI, 그리고 승계 처리의 1~2단계(명분 최고자가 금고·중앙군 상속)까지는 **MVP에 포함**한다. 승계 이후 파벌 처분이 세력 부족으로 실패했을 때의 3~4단계(조정 정치 지속·내전 리스크)는 §9 체크리스트에서 "뼈대만 MVP, 완전한 내전 AI는 2차 범위"로 구분한다.

### 3.5 전체 소속 신하 (명부)
관직 보유자(§3.3) + 지역에 태수·장수로 임명된 인물 + **문객**(아직 공식 직위가 없는 재야 인재 — 전란 중 투항·포로였다가 등용 가능해진 장수, 떠돌이 학자 등)까지 한 화면에서 필터로 넘나든다.
- 필터: 전체 / 관직자 / 일반 신하(지역 임명) / 문객. 정렬: 충성도·능력치·소속 파벌.
- 문객은 **초빙**(엽전/권위 소비)으로 관직(§3.3)이나 지역 임명으로 끌어올릴 수 있음 — 방치하면 다른 세력에 떠날 수도 있음(2차 범위). 원본 기획서 5장의 "포로 삼고초려 등용"이 승낙되면 이 풀에 합류한다.
- 모든 신하는 §3.4의 후계자 파벌에 (있다면) 소속돼 있으며, 여기서 재배치·해임하면 그 파벌 소속도 함께 정리된다.

### 3.6 경제·농업 (시설 관리)
참고로 받은 "시설관리" 레퍼런스는 다른 게임 화면(조선시대 소재, 육각 미니맵·실시간 UI)이라 우리 셸(상단 바·좌측 탭·우측 알림)과 크롬은 다르지만, **좌측에 자원+건축물 목록을 띄우는 내용 구성**은 그대로 가져온다:
- **좌측 패널(또는 중앙 장면 내 목록 영역): 자원 현황** — 자원별로 보유량과 이번 계절 생산율을 한 줄씩(아이콘 + 수치 + %). MVP는 석(쌀)·엽전이 핵심이고, 나무·철·비단 같은 가공 자원은 원본 기획서 5장의 "해상 무역"과 묶어 2차 범위로 둔다(§11).
- **건축물 목록** — 지역에 지은 시설(논/저수지 등)을 레벨 배지 + 다음 레벨 업그레이드 비용(자원 아이콘 조합)과 함께 세로로 나열, 스크롤 가능. 클릭하면 **업그레이드** 실행.
  - MVP 시설: **논(농업 개간)**, **저수지(수리시설)** — 둘 다 레벨업 시 석 생산량 증가. 2차 범위에서 대장간(철)·옹기마당(비단 가공) 등 가공 시설 추가.
- **세율 슬라이더**: 세율↑ = 엽전↑/충성도↓ 트레이드오프.
- 생산 미리보기 (이번 계절 예상 석/엽전 수입).
- 선택된 지역 정보 카드(지역명 등)는 하단 상태바와 겹치지 않게 §3의 공통 셸 영역을 그대로 쓴다.

### 3.7 군사·사병 — "병력 현황"
병력은 두 갈래로 나뉜다 (원본 기획서 4장 "호족 충성도와 신하 관리"를 구체화):
- **중앙군**: 플레이어가 직접 징병·훈련한 상비군. 정예병/특기병종별 보유·정원, 사기 상태 표시. 언제나 100% 동원 가능. 승계 시 새 군주에게 그대로 상속(§3.4).
- **호족 사병**: 복속시킨 호족이 자체적으로 보유한 사병. 목록에 호족 이름·충성도·보유 사병 수. **동원령**을 내리면 충성도에 비례해 동원 응하지만, 충성도가 낮으면 "동원 거부" — 호족 판도 탭에서 충성도를 먼저 올려야 함. 이 설계로 호족 관리와 군사 시스템이 직접 연결된다.
- 장수: 무력·지력·충성·출신 호족 연고·야심 성향, 임명 상태(태수/장수/재야). 부대 편성 시 장수를 지휘관으로 배치.
- 하단 액션바: **동원령 내리기**(호족 사병 소집 시도), **훈련 강화**(중앙군 사기/숙련 상승, 석 소비), **병과 편제 변경**(병종 4종 간 보유 비율 재조정 — §3.9/§3.11 참고).
- **군단(Corps) 편성**: 출진(§3.0)할 때 병력·지휘 장수를 묶어 "제1군단"처럼 이름 붙은 부대로 구성 — MVP는 군단 1개(병력 전체를 한 번에 출진)로 단순화하고, 2차 범위(전국 규모 전쟁)에서 군단을 여러 개 동시 운용하도록 확장한다.

### 3.8 외교·책략
- 인접 세력/호족과의 관계 상태.
- 액션: **정략결혼**(§3.14 혼사 결정 화면을 염 — 동맹·충성 강화), **위협**(복속 요구, 거부 시 명분 획득 후 공격 가능), **첩보**(상대 전력 확인 — 2차 범위).
- 포로로 잡은 적 장수 처리: **등용** 또는 **처형** 선택지 (원본 기획서 5장) — 등용하면 §3.5 문객 풀로.

### 3.9 병영·징집
- 사병 모집 큐 (석/엽전 소모 → 병력 생산, 소요 턴).
- **병종 4종**(출진 부대 편성 화면 §3.11 기준으로 확정): **보병**(步兵)·**기병**(騎兵)·**궁병**(弓兵)·**창병**(槍兵). 각각 모집 비용·소요 턴이 다름. 상성(창병>기병>궁병>창병 같은 RuleTheKingdom식 가위바위보)은 전투 계산에 넣되, 지형별 전투 세분화(평야 기병전/산성 공성전/하천 수전)는 2차 범위.

### 3.10 전투 결과 — MVP는 즉시 계산 팝업, 장기 목표는 실시간 전장
**MVP**: 원정/침공이 해소되는 턴에 뜨는 모달. 아군·적군 병력, 장수 참여, 승패, 노획/손실 요약, 포로 처리 선택지로 연결. §5.5 공식으로 즉시 계산해서 결과만 보여준다(RuleTheKingdom의 BattleSimulator와 동일한 접근).

**장기 목표(2차 범위) — 실시간 전투 화면**: "전투 화면" 레퍼런스가 보여주는 완성형은 숫자 팝업이 아니라 라이브 전장이다. MVP의 §5.5 계산 결과를 이 연출 위에 얹는 식으로 확장한다(계산 로직은 그대로, 표현만 풍부해짐):
- 상단: "전투 진행 중" + 타이머, 양측 세력명과 **총병력 바**(현재/최대, 세력 색).
- 중앙: 두 진영이 맞붙는 전장 일러스트(픽셀아트로 재해석, §8).
- 좌하단: **미니맵**(점으로 양측 병력 배치 표시) + **지휘 장수 초상화**(HP·사기 게이지).
- 하단 중앙: 전투 중 쓰는 **스킬/전술 버튼**(돌격, 사격, 방어 태세 등) + **공격/퇴각** 명령 — 퇴각하면 병력을 일부라도 보존.
- 우하단: **선택된 부대** 패널 — 보병대/기병대 등 병종별 유닛 카드, 개별 손실은 X로 표시.
- MVP는 이 중 "퇴각으로 손실을 줄인다"는 개념만 먼저 가져올 수 있다 — 결과 팝업을 띄우기 전에 "이대로 진행 / 퇴각" 선택지를 하나 넣는 정도로 단순화(§11).

### 3.11 출진 부대 편성
지도(§3.0)에서 공격할 지역을 고르고 "출진" 버튼을 누르면 뜨는 2단 패널. 제목에 "OO(소속 세력 영토) 공격" 같은 목표가 표시된다.

- **좌: 출진 장수 선택** — 이번 출진에 데려갈 장수를 **최대 3명**까지 체크(헤더에 "장수 출진 n/3"). 선택된 3인 중 하나를 **대장**(지휘관, 전투 보정의 중심)으로 지정하고 나머지는 부대장/일반 참전. 카드에 초상화·이름(한자 병기)·레벨 표시.
  - 아래에 나머지 가용 장수 명부가 스크롤 목록으로 이어짐: 상태 태그로 **선택 가능** / **출전 대기**(다른 곳에 이미 배치됨 등) / **출전 불가**(충성도 부족·부상 등)를 구분.
  - 예시 인물(왕건을 중심으로 한 고려 개국공신을 샘플 데이터로 사용): 왕건, 유금필, 신숭겸, 홍유, 배현경, 복사귀.
- **우: 출진 병력 편성** — 상단에 **총 출진 병력 / 보유 상한**(예: 35,000 / 40,000) 진행바. 그 아래 병종 4종(보병/기병/궁병/창병)마다 아이콘 + 슬라이더(−/+ 버튼 병행)로 인원을 배분. 하단에 **소모 식량**(총원에 비례해 자동 계산 — 출정 중 보급 비용, §3.9의 모집 비용과는 별개).
  - **자동 편성** 버튼: 보유 장수·전황에 맞춰 병종 비율을 자동으로 채움.
- 하단: **출진**(出陣, 행군 시작) / **전투 시작**(도착 즉시 교전 — 테스트·즉시 전투용 단축, §3.0의 "행군 → 도착 시 전투" 2단계와 호환).
- MVP는 **장수 수 상한을 1명**(대장만)으로 단순화할 수 있다 — 완산주 규모 교전에선 3인 편성까지는 2차 범위에서 자연스럽게 의미가 생김(§11).

### 3.13 거점 승격 (팝업)
지역이 §6.1·§5.6의 승격 조건을 모두 채우면 뜨는 전체화면 축하 모달. 서양식 작위가 아니라 **한국 삼국·후삼국시대의 실제 행정구역 승격**(촌→현→군→주→경)을 그대로 연출로 가져간다.
- 상단 배너: "거점 승격" 제목 + "현(縣) → 군(郡) 승격 완료!" 식 등급 전환 문구, 용·봉황 금박 장식.
- **좌: Before/After 일러스트** — 토성·목책으로 둘러싸인 초라한 거점에서 기와지붕·석성이 들어선 거점으로 바뀌는 모습을 한 장면 안에 대비시켜 보여준다(승격 전/후 스프라이트를 나란히, 또는 한 장면에서 전환 이펙트로).
- **우: "작위" 혜택 목록** — 아이콘 + 한 줄 설명으로: 새로 임명 가능해진 관직(예: 군수/태수), 세금 징수량 증가율, 새로 지을 수 있는 건축물(예: 석성), 해금된 정예 병종(예: 광군·군영).
- 하단: **확인** 버튼 하나로 닫기 (턴을 막지 않는 정보성 모달).

### 3.14 혼사 결정
§3.2의 "정략결혼 제안"과 §3.8의 "정략결혼"이 공통으로 여는 화면. 호족 충성도 확보 수단에 그치지 않고, **플레이어 자신이나 자녀(후계자 포함, §3.4)를 호족·신하의 자녀와 혼인시켜 세력을 강화하는** 독립된 상호작용으로 승격한다.

- **좌: 혼인 당사자 선택** — 플레이어 본인 또는 자녀 중 한 명을 고른다. 카드에 초상화, 신분(장남/차남 등 + 소속 가문), 7스탯(§7 RetainerDef) 중 핵심 지표. 후계자를 고르면 §3.4의 명분 점수·지지도에도 영향을 줄 수 있다(혼인으로 맺은 가문의 지지를 얻음).
- **우: 정혼자 후보 목록** — 호족(§3.2)과 조정 신하(§3.5)의 자녀들이 카드로 제시된다(매 계절 일부 교체). 각 카드: 소속(「OO 호족/신하 OOO의 장녀/차남」) + 가문명, **혼인 시 얻는 고유 효과**(후보마다 다름 — 예: 군사 지원 철기병 200, 조정 영향력 +30·신하 충성도 상승, 재정 수입 +40%·군량미 5,000석 등), **혼인하기** 버튼.
- 혼인이 성사되면: 그 가문과 영구 동맹(§3.2의 "정략결혼 제안"과 동일하게 충성도 고정 + 이탈 불가, 되돌릴 수 없음) + 카드에 적힌 고유 보너스 지급.
- 하단: **돌아가기**, **세력 정보**(후보 가문이 속한 세력의 전력·관계를 미리 확인).
- 예시 인물(실존 고려 개국 관련 호족을 샘플 데이터로 사용): 명주 호족 김순식의 장녀, 평산 박씨(박지윤의 차남 — §3.3 관직자와 동일 인물 가문 재사용), 패서 호족 유천궁의 외동딸.

### 3.15 자식 교육(子息 敎育)
§3.4의 "후계자 교육"이 여는 화면. 자녀(후계자 포함)를 7스탯(§7 RetainerDef) 인재로 키운다.

- **좌: 교육 대상** — 자녀 중 한 명 선택. 초상화, 신분(장남 등 + 가문), 현재 스탯(무력/학문/덕망/지력 등, 이번 교육으로 오른 만큼 "+N" 녹색 표기), **남은 교육 횟수**(계절당 예산, 예: 3/3 — 교육은 무제한이 아니라 계절마다 정해진 횟수만), **스승**(배정된 경우 이름 + 특화 분야 — §3.5 전체 소속 신하에서 학식 높은 인물을 스승으로 지정하면 해당 분야 교육 효과가 커짐).
- **우: 교육 분야 선택** — 4개 카드, 각각 버튼으로 실행(1회당 교육 횟수 1 소비):
  - **무예 수련**(武藝 修鍊) — 무력 대폭 상승, 통솔 상승. "훈련하기"
  - **경서 강독**(經書 講讀) — 학문 대폭 상승, 지력 상승. "학습하기"
  - **병법 및 정세** — 지력 대폭 상승, 정치 상승. "지도하기"
  - **예법 및 덕행**(禮) — 덕망 대폭 상승, 매력 상승. "교육하기"
- 하단: **돌아가기**, **교육 완료**(이번 계절 교육 확정), **가문 정보**.
- 자녀의 스탯이 쌓이면 §3.4 명분 점수(장자가 무능하면 깎이고 유능한 차남이 오른다는 설계)와 §3.14 혼인 매력에도 그대로 반영된다 — 교육·혼인·계승이 같은 스탯을 공유하는 하나의 시스템이다.

### 3.16 민심 관리(民心 管理)
§3.1 영지 개요의 지역별 심층 관리 화면 중 하나. **호족 충성도(§3.2, §5.2)와는 다른 축** — 호족은 귀족·신하의 정치적 이탈을 다루고, 민심 관리는 **그 지역 백성(평민)의 봉기 리스크**를 다룬다. 둘 다 "반란"으로 이어질 수 있지만 원인과 대응 수단이 다르다.

- **좌: 영지 상황 카드** — 선택된 지역 이름 + 백성이 모인 삽화. 지표: **민심도**(0~100, 상태 라벨 예: "45/100 (불안)"), **치안도**(0~100, "52/100 (보통)"), 세금 세율(§3.6의 세율 슬라이더와 연동), **재난 상태**(가뭄 등 — 주기적으로 발생하는 지역 이벤트, §EventSystem), **반란 위험도 %**(민심·치안·재난을 종합한 계산치 — 백성 봉기 전용 리스크, 호족 이탈 리스크와는 별개 수치), 지역 자금·보유 군량.
- **우: 민심 대책 4종** — 각각 다른 자원을 소모해 민심/치안/피로도를 조정:
  - **구휼미 방출**(救恤米 放出) — 군량(=석) 대량 소모 → 민심도 대폭 상승.
  - **부역 감면**(賦役 減免) — 자금(엽전) 소모 → 민심도·치안도 상승.
  - **도적 토벌**(盜賊 討伐) — 군사(병력) 소모(파병) → 치안도 대폭 상승, 민심도 상승.
  - **대동 축제**(大同 祝祭) — 자금 소모 → 민심도 상승, **피로도**(신규 지표 — 과도한 부역·동원 누적치, 높으면 생산성 저하) 감소.
- 하단: **돌아가기**, **관리 완료**, **영지 정보**.
- MVP는 재난·피로도까지 전부 넣기보다, **민심도·치안도·반란 위험도 + 대책 2~3개**로 축소하는 것도 선택지(§11).

### 3.17 엔딩 화면 (팝업)
완산주 전체를 통일해 §6.2의 도독 작위에 오르면 뜨는 MVP 최종 화면. 다음 턴으로 넘어가지 않고 게임을 마무리한다.
- 통일까지 걸린 계절 수, 최종 영토·신하·호족 현황을 요약하는 엔딩 일러스트(§8 PixelLab 재해석).
- "2단계(도 단위)로 이어가기"는 넣지 않는다(§11에서 MVP는 엔딩에서 종료로 확정) — 대신 "새 게임" / "제목으로" 버튼만.

### 3.18 시나리오 선택 (게임 시작 화면)
새 게임을 누르면 가장 먼저 뜨는 화면. **시대(연도)와 그 시점에 고를 수 있는 인물**을 함께 선택해 시작한다 — §2.3 신분별 플레이의 "코에이 삼국지 장수제" 지향을 MVP 수준에서 미리 열어 두는 창구.
- 좌: **시나리오(시대) 목록** — 연도 + 한 줄 설명(예: "900년, 후삼국 초기 — 완산주의 이름 없는 호족으로 시작"). `ScenarioDef`(§7)로 데이터화해 나중에 항목만 추가하면 됨.
- 우: 고른 시나리오에서 **플레이 가능한 인물 목록** — 초상화, 소속 세력, 시작 지위(호족/장수 등, §2.3). MVP는 시나리오마다 1~3명 정도만 채워 둔다(예: 900년 시나리오엔 완산주의 무명 호족 하나, 추후 927년 같은 시나리오를 추가하면 왕건·견훤 등 실존 인물도 고를 수 있게).
- 하단: **시작하기**.
- 데이터만 늘리면 되는 구조라 — 처음엔 MVP 시나리오 하나(900년 완산주)만 넣고, 이후 세션에서 시나리오·인물을 계속 추가해 나간다.

## 4. 핵심 루프 (계절 턴)

```
   ┌────────► 내정 (농업·수리시설·세율) ────────┐
   │                                            ▼
 외교/호족                                     군사
(회유·혼인동맹                            (징병·장수 편성
 ·위협)                                     ·원정 출발)
   ▲                                            │
   └──────────── 전투 결과 · 충성도 변화 ◄───────┘
```

- **계절(턴) 시작**: 생산 정산(석/엽전/권위), 진행 중인 건설·모병·원정 진행, 이벤트 발생(두루마리 알림).
- **플레이어 행동 단계**: 내정/호족/군사/외교 탭에서 원하는 만큼 명령을 내림 (행동력 제한 없음, MVP는 자유 행동).
- **턴 종료**: "다음 턴" 버튼 → AI 세력이 자기 행동을 1회씩 수행 → 다음 계절로. **AI는 수세적이지 않다** — 자기 전력이 충분하다고 판단하면 플레이어나 다른 호족의 약한 지역을 먼저 공격한다(§5.8).

### 5.2 호족 충성도
- 충성도 0~100. 낮으면 세금 체납·이탈 확률 상승 (원본 기획서 4장 "반란 리스크").
- 세율이 높을수록, 방치(아무 액션 없이 지나간 턴 수)할수록 충성도 하락.
- 회유 1회 = 엽전 소비, 충성도 +N. 인질 = 충성도 상한 확장이지만 "반감" 플래그(미래 반란 시 가중치). 혼인 동맹 = 권위 소비, 충성도 고정(이탈 불가) — 대신 되돌릴 수 없음.

### 5.3 신하·관직 (§3.3, §3.5)
- 신하는 세 상태 중 하나를 가진다: **관직자**(대상서/대장군/내사령 중 하나에 임명, 왕국 전체에 effect 적용), **일반 신하**(지역 태수·원정 지휘관 등으로 임명, 해당 지역/부대에만 effect 적용), **문객**(미소속 — effect 없음, 초빙 전까지 대기).
- 관직 3종은 각각 분야별 effect 하나씩 제공(§3.3 표). 공석이면 효과 없음. 교체(임명 변경)는 즉시 적용되지만 전임자의 소속 호족과의 관계에 영향을 줄 수 있음(2차 범위에서 세분화).
- 호족을 중앙 관직·신하로 끌어들이는 것 자체가 **충성도 관리 수단**이다 — "인사 제안" 이벤트(§3.3)가 이를 플레이어에게 안내.
- 파면 및 유배는 즉시 공석화 + 해당 인물 충성도 초기화(다시 등용하려면 문객부터) + 출신 호족 충성도 하락 리스크.
- 모든 신하는 §5.4의 후계자 파벌에 (있다면) 소속되어, 신하 관리 액션이 승계 정치에도 영향을 준다.

### 5.4 왕위 계승 (§3.4) — 명분 점수제
- **명분 점수** = 출생 순서 보너스(장자 기본값 가장 높음) + 능력·공적 누적 가감(전투 승리·내정 성과 → 가산, 실정·무능 → 감산) + 플레이어 액션 보정(태자 책봉 확정 = 고정 보너스, 후계자 지지 선언 = 소폭 가산, 후계자 교육 = 서서히 가산). **장자 고정이 아니라 매 턴 재계산**되는 값 — 유능한 차남이 역전할 수 있다.
- **지지도 %** = 명분 점수와 별개로, 조정 신하·호족 각자가 자신의 성향(능력 중시/적통 중시/인맥 등)에 따라 어느 후계자를 지지하는지 집계한 비율. MVP는 "관직자·주요 신하 1인 1표, 영향력(관직 보유 여부)으로 가중"으로 단순화. §5.3의 관직 임명이 이 집계에 직접 반영된다.
- **파벌**: 같은 후계자를 지지하는 신하·호족 묶음. 우측 "조정 파벌 판도"에 파벌 단위로 노출(§3.4).
- **승계 처리** (2차 범위에서 완전 구현, MVP는 데이터 구조·상시 관리 UI만):
  1. 군주 교체 시점의 **명분 점수 최고 후계자**가 계승 → 왕실 금고(엽전)와 중앙군을 그대로 상속.
  2. 신군주의 **세력**(중앙군 규모 또는 권위)이 임계치 이상이면 낙선 후계자의 파벌을 처분(파면/숙청) 가능.
  3. 세력 미달 시 파벌 존속 → "조정 정치" 상태(정책 반대, 충성도 지속 악화)로 전환.
  4. 방치하면 파벌이 다른 왕족을 옹립해 결집 → 반란/내전 리스크로 발전(완전한 내전 AI는 2차 범위, MVP는 파벌 불만도가 임계치를 넘으면 지역 이탈/반란 이벤트로 단순화).

### 5.5 전투 (MVP 단순화)
- 원본 기획서 5장의 "평야 기병전/산성 공성전/하천 수전" **지형별 세분화**는 2차 범위. 다만 **병종 4종(보병/기병/궁병/창병)과 상성**은 §3.11 출진 화면이 이미 전제하고 있어 MVP에 포함한다.
- MVP 공식: 병종별로 `병종 전투력 = 인원 수 × 상성 배율(RuleTheKingdom의 counterBonus/counterPenalty 패턴 재사용)`을 구해 합산 → `부대 전투력 = Σ병종 전투력 × (1 + 대장 무력/100) × 지형 보정(MVP는 1.0 고정)`. 상대도 동일 계산 후 비율로 승패·손실 결정 + 약간의 무작위성(시드 저장 → 재현 가능, RuleTheKingdom의 BattleSimulator 패턴 재사용).
- 패전한 적 장수는 포로로 잡힐 수 있음 → 등용/처형 선택지.

### 5.6 거점 등급 (§6.1, §3.13)
- 지역(ProvinceState)마다 **인구**(§3.6 건축물로 늘어나는 주거/생산 규모)·**군사적 중요도**(주둔 병력 수 또는 해당 지역에서 치른 승전 횟수 누계)·**경제력**(누적 세수 또는 자원 생산량)을 추적한다.
- 세 지표가 각각 다음 등급의 임계치를 모두 넘으면 **승격 가능** 상태가 되고(필요하면 추가 자원 비용도), 플레이어가 승인하면 §3.13 팝업과 함께 즉시 적용된다 — 자동 승격이 아니라 **플레이어 확인 액션**으로 둬서 연출을 살린다.
- 승격 시 적용: 세금 징수율 보너스(등급마다 누적), 상위 건축물(토성→석성 등) 해금, 그 등급에 맞는 관직(현령/태수/도독 등급)만 §3.5에서 임명 가능해짐, 정예 병종(예: 광군·군영) 훈련 해금.
- 호족이 다스리는 지역(§3.2)도 같은 등급 체계를 쓴다 — 미복속 호족의 거점 등급이 높을수록 그 호족의 병력·위협도가 크다는 뜻이 되어 호족 판도 지도의 난이도 신호로도 쓸 수 있다.

### 5.7 민심·치안 (§3.16)
- **민심도**·**치안도**는 지역(ProvinceState)마다 따로 가지는 0~100 수치. 세율이 높을수록, 재난(가뭄 등 — 주기적 랜덤 이벤트, §EventSystem)이 발생 중일수록 민심도가 깎인다. 치안도는 도적 등 치안 이벤트 빈도·피해에 영향.
- **반란 위험도 %** = 민심도·치안도·재난 여부를 종합한 계산치. **호족 충성도(§5.2)의 반란 리스크와는 별개 트랙**이다 — 호족 충성도가 높아도 그 지역 백성 민심이 바닥이면 평민 봉기가 일어날 수 있고, 반대로 호족이 이탈해도 민심 자체는 안정적일 수 있다. 둘 다 임계치를 넘으면 반란 이벤트로 이어지되, 호족 쪽은 "그 호족이 독립/이탈", 민심 쪽은 "그 지역에서 봉기 발생(생산 중단·치안 추가 악화)"로 결과가 다르다.
- **피로도**: 부역·동원(출진·대규모 건설 등)이 누적되면 오르고, 대동 축제 같은 대책으로 내린다. 높으면 생산성에 페널티.
- 대책 4종(§3.16)은 각각 석/엽전/병력 중 하나를 소모해 민심·치안·피로도를 조정 — §5.1 자원 소비처에 민심 대책이 추가된다.

### 5.8 AI (MVP부터 공격적)
- AI 세력(인접 호족·경쟁 성주)은 수세적이지 않다. 매 턴 간단한 점수화로 행동을 고른다: 자기 병력이 목표 지역 수비력보다 충분히 크면(예: 1.3배 이상) **공격**, 아니면 **내정**(§3.6 건물 레벨업)이나 **호족 회유**(자기 세력 내 불안정 지역 단속) 중 하나.
- 목표 선택: 가장 약해 보이는 인접 지역(수비력 낮음, 충성도 낮음) 우선 — 꼭 플레이어가 아니어도 다른 호족끼리도 서로 공격할 수 있다(완산주 일대의 정세가 플레이어 없이도 바뀜).
- MVP는 이 정도 휴리스틱으로 충분 — 명분 점수나 파벌 정치(§5.4)까지 고려하는 "똑똑한" AI는 2차 범위.

### 5.9 군주 수명과 자연 승계 (§3.4)
- RetainerState에 **나이**를 둔다. 계절(턴)마다 나이가 쌓이고, 일정 연령(예: 50세)을 넘으면 매 턴 자연사 확률이 서서히 오른다(RuleTheKingdom의 확률 기반 이벤트와 같은 패턴).
- 군주(FactionState.현재 군주)가 사망하면 그 즉시 §5.4 승계 처리가 발동 — 명분 점수 최고 후계자가 즉위. 후계자가 아무도 없으면(자녀 없음/전멸) 세력이 와해되는 조건으로 이어질 수 있음(2차 범위에서 다른 호족의 흡수 대상이 되는 식으로 처리).
- 자녀는 §3.15 자식 교육을 거치며 7스탯이 쌓이다가, 일정 나이(예: 15세)가 되면 "성인" 처리돼 §3.4 후계자 목록에 정식으로 올라간다(그전엔 교육 대상으로만 존재).
- MVP 플레이 길이(완산주 통일까지)에서도 수십 턴이 걸릴 수 있어 **계승이 실제로 한 번쯤 일어날 가능성**이 있다 — §5.4의 "MVP는 데이터 구조·UI만" 전제를 재검토해, 적어도 **승계 처리 1~2단계(명분 최고자가 금고·중앙군 상속)까지는 MVP에 포함**하고, 3~4단계(파벌 처분/내전)는 여전히 뼈대만 두는 것으로 조정한다.

## 6. 성장 구조

성장은 두 축으로 나뉜다: **거점 등급**(지역 하나하나가 독립적으로 밟는 행정구역 승격 단계)과 **플레이어 작위**(전체 세력 규모에 따른 군주 개인의 서열). 서양식 백작·공작이 아니라 한국 삼국·후삼국시대의 실제 행정구역 승격 체계(촌→현→군→주→경)를 거점 등급으로 쓰는 것으로 확정한다.

### 6.1 거점 등급 (ProvinceState 각각에 적용)

| 등급 | 한자 | 설명 | 부임 관직 |
|---|---|---|---|
| 촌 | 村 | 외딴 마을, 최하위 거점 | 촌주 (비공식, 관직 임명 불필요) |
| 현 | 縣 | 기초 행정·교역의 시작 | 현령/현감 |
| 군 | 郡 | 군사 요충지이자 거점 도시 | 태수/군수 |
| 주 | 州 | 대도성, 거점 대도시 | 도독/방어사/총독 |
| 경 | 京 | 수도급 요충지 (개경·서경·완산주 등) | — (군주 직할 또는 최고위 임명) |

- **승격 조건**: 해당 지역의 **인구**·**군사적 중요도**(주둔 병력·승전 횟수)·**경제력**(누적 생산·세수)이 각 등급의 임계치를 모두 넘으면 승격 가능(§5.6).
- **승격 시 해금**(현→군 예시, §3.13 "거점 승격" 팝업 기준): 그 등급에 맞는 **관직 임명 가능**(§3.3/§3.5에서 현령→태수 등으로 임명), **세금 징수량 증가**(+15% 등 등급별 보너스), **상위 건축물 해금**(토성/목책 → 석성), **정예 병종 훈련 해금**(예: 군 등급에서 광군·군영 정예병).
- 등급이 오르면 지역 비주얼도 토성·목책 마을에서 기와·석성 거점으로 바뀐다(§8 아트 — PixelLab 재해석 대상).
- 완산주 같은 **거점 대도시는 시작부터 주(州)급 이상**으로 설정하고, 플레이어의 작은 성(§1.2 MVP 시작 지점)은 **촌 또는 현** 등급에서 시작한다.

### 6.2 플레이어 작위 (세력 전체 규모)

원본 기획서 4장의 작위 체계(대군장-도독/자사-성주-호민)를 쓰되, **플레이어 자신의 서열은 본인 거점(수도로 삼은 지역)의 등급에 연동**하고, 지배 지역 수는 보조 조건으로 둔다.

| 작위 | 조건 (MVP) | 해금 |
|---|---|---|
| 호민 | 시작 (본인 거점 = 촌/현) | 영지 개요, 경제·농업 |
| 성주 | 본인 거점이 군(郡) 등급 + 지역 2곳 이상 복속 | 호족 판도, 병영·징집 |
| 자사 | 본인 거점이 주(州) 등급 + 지역 5곳 이상 (완산주 과반) | 외교·책략, 주요 관직 임명 |
| 도독 | 완산주 전체 통일 (완산주 자체가 경(京)급) | **MVP 승리 조건** — 2단계(도 단위)로 이어지는 엔딩 컷 |

## 7. 데이터 구조 설계 (ScriptableObject)

`RuleTheKingdom`과 같은 데이터 주도 방식을 쓰되, 턴제 전략에 맞게 구성한다.

```

                각 인물은 RetainerDef 참조 + 시작 factionId/provinceId)
FactionDef      세력 하나의 정의 (id, 국호, 군주명, 색상, 세력 성향 보너스)
ProvinceDef     지역 하나의 설계도 (id, 표시이름, 인접 지역 id 목록, 지도 좌표,
                시작 소속 세력, 기초 농업/수리시설/인구, 시작 거점 등급)
SettlementTierDef 거점 등급 하나의 정의 (촌/현/군/주/경) — id, 한자 표기, 승격 임계치
                (인구/군사적 중요도/경제력), 임명 가능 관직 등급, 세금 보너스율, 해금 건축물·병종 id 목록
RetainerDef     신하(장수·문관·왕자 통칭) 하나의 정의 — **7스탯**: 전통 삼국지류 5스탯인
                **통솔·무력·지력·정치·매력**에 이 게임 고유의 **학문**(지력과 별개로 교육을 통해
                오르는 소양)·**덕망**(혼사·명분·충성도 상호작용에 쓰는 평판)을 더함 (§3.15 자식 교육
                기준 — "자식 교육(子息 敎育)" 화면에서 확인). MVP는 역할별로 일부만 노출해도 됨
                (장수는 무력·통솔 중심, 관직자는 정치·학문 중심, 후계자는 전체). 그 외 이름, 출신 지역
                연고, 야심 성향, 초상화) — 호족 출신 여부는 originHojokId로 표시해 §3.3 "인사 제안"
                같은 호족-신하 연결 훅에 쓴다. isHeir + birthOrder로 군주의 자녀(후계자 후보)도
                같은 정의를 재사용한다 (능력치가 이미 있으므로 명분 점수 계산에 그대로 쓸 수 있음)
OfficeDef       주요 관직 정의 (대상서/대장군/내사령) — id, 명칭, 분야(행정/군사/외교),
                effect 종류 + 수치
UnitDef         병종 하나의 정의 (보병/기병/궁병/창병) — id, 표시이름, 상성 클래스(RuleTheKingdom의
                UnitClass 재사용), 모집 비용·소요 턴, 전투력 기초치, 행군 시 1인당 소모 식량
ResourceDef     석/엽전/권위 등 자원 정의 (id, 표시이름, 아이콘)  — RuleTheKingdom과 동일 패턴
GameDatabase    위 정의들의 목록 + MVP 밸런스 수치 (세율 상한, 충성도 임계치, 전투 상수,
                적통 장자 명분 보너스 등)
```

## 8. 아트 / 사운드

- **아트 파이프라인 결정**: `RuleTheKingdom`과 동일하게 **PixelLab**(api.pixellab.ai) 연동으로 간다. 지금까지 받은 참고 이미지들은 회화풍/반실사 일러스트(한옥 창틀, 전장 삽화 등) 톤이라 PixelLab의 픽셀아트 출력과는 결이 다르므로, 실제 제작 시 이 레퍼런스들의 **구도·정보 배치**는 그대로 따르되 **그림체는 픽셀아트로 재해석**해서 뽑는다 (RuleTheKingdom의 32px·Point 필터 규격 재사용 가능성 높음 — 구체적 해상도는 실제 생성 테스트 후 확정).
- MVP 단계에서는 실제 아트가 없어도 진행 가능하도록, 중앙 장면은 placeholder(단색 배경 + 설명 텍스트)로 먼저 구성하고 레이아웃만 최종 구도에 맞춘다.
- 폰트: `RuleTheKingdom`과 동일하게 갈무리(Galmuri) 재사용.
- **사운드 방향 (2차 범위)**: 국악기(대금·거문고·장구·꽹과리·가야금·아쟁) + 오케스트라/앰비언트 융합. 세력별 테마(고려=북·징의 진취적 군가풍, 후백제=꽹과리·해금의 야성적 돌파풍, 신라=가야금·아쟁의 우아한 쇠퇴풍), 계절별 환경음(§2.8과 연동 — 봄 새소리/농민 웅성거림, 여름 빗소리·범람, 가을 바람·수확, 겨울 삭풍·얼음 갈라지는 소리), 전투 타격음(찰갑 마찰음, 기병 돌격 저음, 사기 붕괴 징소리), UI 피드백음(두루마리 펼침, 대장간 단조음, 턴 종료 인장 소리) — 실제 작곡/SFX 제작은 아트 파이프라인이 자리잡은 뒤의 후속 작업.

## 9. MVP 범위 체크리스트

- [ ] 지도 화면: 완산주 일대 8~10개 지역 노드 + 인접 그래프, 소속 세력 색
- [ ] 공통 셸 UI (상단 바·좌측 탭·우측 알림·하단 상태바·책상 지도) + §3의 화면들(영지 개요/호족 판도/주요 관직/왕위 계승/전체 신하/경제·농업/군사·사병/외교·책략/병영·징집)
- [ ] 계절 턴 진행 (생산 정산, 건설/모병/원정 진행, "다음 턴" 버튼)
- [ ] 자원 4종: 석·엽전·권위·병력
- [ ] 호족 충성도 + 회유/인질/숙청, 혼사 결정 화면(§3.14 — 당사자 선택·후보별 고유 혜택·혼인하기)
- [ ] 관직 3종(대상서/대장군/내사령) 임명·파면 + 왕국 전체 effect 적용
- [ ] 신하 데이터 + 임명/재배치 (등용은 포로 처리·문객 초빙에서 트리거)
- [ ] 후계자 명분 점수·지지도 계산 + 태자 책봉/지지 선언/교육/폐위 UI (승계 발생 시 파벌 처분/내전은 뼈대만 — §5.4)
- [ ] 자원 현황 + 건축물(논/저수지) 레벨·업그레이드 비용 목록 (§3.6)
- [ ] 병종 4종(보병/기병/궁병/창병) 모집 + 출진 부대 편성(장수 최대 3인·대장 지정, 병력 슬라이더, 소모 식량) — §3.11
- [ ] 상성 포함 전투 해석 (원정/침공) + 결과 팝업 + 포로 등용/처형
- [ ] 세율 조정 + 농업/수리시설 업그레이드
- [ ] 거점 등급(촌/현/군/주/경) 승격 판정 + 거점 승격 팝업(§3.13) + 등급별 관직·세율·건축물·병종 해금
- [ ] 자식 교육 화면(§3.15 — 7스탯, 교육 분야 4종, 스승 배정) + 민심 관리 화면(§3.16 — 민심도/치안도/반란 위험도 + 대책 4종)
- [ ] AI 적대 세력의 선제 공격(§5.8) — 수세적이지 않고 매 턴 공격/내정/회유를 스스로 판단
- [ ] 군주 나이·자연사 + 승계 1~2단계(명분 최고자가 금고·중앙군 상속, §5.9) + 엔딩 화면(§3.17)
- [ ] 좌측 탭을 영지/호족·신하/군사/외교 4개 상위 탭 + 서브탭으로 구성(§3 "좌측 탭 구조 확정")
- [ ] 사성(賜姓) 액션 — 호족 판도(§3.2)의 다섯 번째 호족 대책
- [ ] 완산주 통일 시 MVP 승리 처리 → 엔딩 화면으로 종료(2단계 이어가기 없음)
- [ ] 저장/불러오기 (JSON)

2차 범위(기획서 원안의 나머지 + 화면 반영 중 늘어난 항목): 태봉·신라 본격 참전과 세력별 고유 메카닉(§2.1 — 관심법, 골품제, 후계 갈등, 해상무역), 역사 이벤트 5종 담화·컷신(§2.2), 지형별 전투 세분화(평야/산성/수전), 다수 군단 동시 운용, 해상 무역(나무/철/비단 가공 시설), 도(道) 단위 이후 전국 통일, 승계 3~4단계(파벌 처분 실패 시 내전·파벌 AI), 문객 이탈.

3차 범위(더 먼 미래): 신분별 플레이(§2.3) — 호족이 아닌 장수·문관·근시 등 다른 신분으로 시작하는 모드.

## 10. 기술 설계 (Unity)

- **데이터 주도**: 자원·세력·지역·장수는 ScriptableObject로 정의, `GameDatabase`에 등록 (§7).
- **턴 시뮬레이션**: 실시간이 아니라 "다음 턴" 버튼으로 진행하는 명시적 틱 — `TurnManager.AdvanceSeason()` 하나가 모든 시스템의 턴 훅을 순서대로 호출.
- **저장**: `JsonUtility` → `persistentDataPath/save.json` (RuleTheKingdom과 동일 패턴). 실시간 게임이 아니므로 자동저장은 턴 종료 시점 + 수동 저장.
- **UI**: UI Toolkit, 셸(상단 바/좌측 탭/우측 알림/하단 상태바)과 탭별 콘텐츠를 분리해 구성. 기준 해상도 1920×1080 (초안 이미지 비율 기준, RuleTheKingdom의 1280×720보다 넓음).
- **맵**: 격자가 아니라 지역 노드 그래프 (좌표 + 인접 리스트). Tilemap/Grid 불필요.
- **폴더 구조**

```
Assets/_Project/
  Scripts/Data      정의 (ScriptableObject): FactionDef, ProvinceDef, RetainerDef, OfficeDef, UnitDef, ResourceDef, GameDatabase
  Scripts/Core      GameManager, TurnManager, 세이브
  Scripts/Systems   EconomySystem, LoyaltySystem, RetainerSystem, SuccessionSystem, MilitarySystem, DiplomacySystem, BattleSystem, EventSystem
  Scripts/UI        셸 + 탭별 화면 (UI Toolkit)
  Scripts/Editor    샘플 데이터 세팅 (KingdomSetup과 동일한 역할)
  UI/               USS 스타일시트 (한옥/단청 톤)
  Fonts/            갈무리
  Art/Sprites/      실제 일러스트 (파이프라인 결정 후)
  Data/ Scenes/ Prefabs/   (에디터 메뉴가 생성)
```

## 11. 결정이 필요한 사항 (Open Questions)

1. ~~**아트 파이프라인**~~ → **PixelLab 연동으로 확정** (§8). 레퍼런스 이미지들의 회화풍 그림체를 픽셀아트로 어떻게 재해석할지는 실제 생성 테스트에서 구체화.
2. ~~**지도 화면의 시각적 형태**~~ → **일러스트 3D 지형 지도로 확정** (§3.0, v0.4).
3. ~~**AI 세력의 적극성**~~ → **AI는 MVP부터 공격적** (§5.8) — 충분히 강하다고 판단하면 플레이어든 다른 호족이든 먼저 공격한다.
4. ~~**승리 후 흐름**~~ → **MVP는 엔딩 화면에서 종료** (§3.17), 2단계로 자동 연결하지 않는다.
5. ~~**세이브 슬롯**~~ → **단일 슬롯**으로 결정 (RuleTheKingdom과 동일 패턴, MVP 단순화).
6. ~~**좌측 탭 깊이**~~ → **상위 탭 4개(영지/호족·신하/군사/외교) + 서브탭**으로 확정 (§3 "좌측 탭 구조 확정").
7. ~~**계승 트리거 방식**~~ → **군주 수명·자연사 시스템**으로 확정 (§5.9). 양위 버튼은 넣지 않는다.
8. ~~**시설관리 레퍼런스의 자원 확장**~~ → **2차 범위 유지** — MVP는 석·엽전·권위·병력 4종만.
9. ~~**출진 장수 상한**~~ → **MVP는 대장 1인**으로 단순화 (§3.11). 3인 편성은 2차 범위(전국 규모 전쟁)에서 의미가 생길 때 연다.
10. ~~**퇴각 선택지**~~ → **MVP에 포함** — §3.10 즉시 계산 팝업 앞에 "이대로 진행/퇴각" 선택 1단계만 추가 (실시간 전투 연출 자체는 여전히 2차 범위).
11. **거점 등급 임계치** — 디자인 결정이 아니라 수치 밸런싱 문제로 재분류. 구현 단계에서 `tools/balance`(RuleTheKingdom 패턴 재사용) 스크립트로 시뮬레이션해 확정하기로 하고 Open Question에서 제외.
12. ~~**민심 관리 MVP 범위**~~ → **축소판으로 확정**: MVP는 민심도·치안도·반란 위험도 + 대책 2종(**구휼미 방출**, **도적 토벌**)만. 부역 감면·대동 축제와 피로도·재난은 2차 범위.
13. ~~**7스탯 vs 기존 축약 서술 정합성**~~ → §3.2·§3.4 등의 "무력/지력/충성/야심 성향" 같은 축약 표현은 **7스탯 중 그 장면에 관련된 일부만 보여주는 것**으로 일관되게 해석한다(§7 RetainerDef에 이미 명시). 전체 스탯 카드가 필요한 화면은 §3.15 자식 교육, §3.11 출진(레벨만), §3.14 혼사(전체 요약) 정도이고 나머지는 요약 표기로 충분 — 별도 리라이트 패스는 불필요.
