# 후삼국 대란: 천하통일 — 게임 기획서 (MVP, v0.1)

> 변방의 말단 호족(성주)으로 시작해 후삼국을 통일하는 한국식 역사 전략 시뮬레이션
> 삼국지(장수·전투) × 크루세이더 킹즈(가문·신하 통제) 스타일

원본 기획 의도는 [`원본 기획서`](./원본_기획서_요약.md) 참고. 이 문서는 그중 **MVP로 먼저 만들 범위**를 화면 구성과 시스템 단위로 구체화한 것.

---

## 1. 개요

| 항목 | 내용 |
|---|---|
| 장르 | 턴제(계절 단위) 역사 전략 시뮬레이션 |
| 테마 | 9세기 말~10세기 초 후삼국 시대, 한국적 정체성 |
| 시점 | 2D UI 중심 — 책상에서 창문으로 영지를 내다보는 구도 (§3 참고) |
| 엔진 | Unity 6 (2D, URP), UI Toolkit |
| 플랫폼 | PC 우선 |
| 턴 길이 | **계절 단위** (봄·여름·가을·겨울 = 1년 4턴) |

### 1.1 한 줄 컨셉
"작은 성 하나에서 시작해, 호족의 마음을 얻고 군사를 길러 천하를 통일한다."

### 1.2 디자인 기둥
1. **읽히는 정세** — 지도 한 번만 봐도 누가 누구 땅인지, 내 다음 목표가 어딘지 보인다.
2. **사람이 전략이다** — 영토보다 호족의 충성과 장수의 재능이 승부를 가른다.
3. **계절마다 결정** — 한 턴(계절)에 내정·외교·군사 중 우선순위를 고르게 만든다.

---

## 2. 세계관 및 플레이 세력

(원본 기획서 2장 요약 — 기획서에 세 세력의 지형·성향이 정의되어 있음)

| 세력 | 거점 | 특성 |
|---|---|---|
| 고구려 계열 (태봉) | 철원·송악·평양 | 북방 기병 보너스, 호족 연합체 성향, 확장성 높음 |
| 백제 계열 (후백제) | 완산주·나주·청주 | 호남 평야 식량 생산력, 해상 무역, 호전적 군사력 |
| 신라 계열 (경주) | 서라벌 및 잔여 호족 | 유교·불교 명분, 중앙 집권력 회복, 방어전 유리 |

**MVP 범위**: 플레이어는 **백제 계열 완산주의 말단 성주**로 시작한다 (원본 기획서 1단계 "촌락 및 소규모 성"). 목표는 완산주 일대 호족을 복속시켜 **주(州) 단위 통일**을 이루는 것까지 — 원본 기획서의 4단계 중 1단계 완료 + 2단계 진입이 MVP의 승리 조건이다. 태봉·신라는 MVP에서는 지도 가장자리의 "다른 나라" 취급 (상호작용 없음), 2차 범위에서 본격 참전.

## 3. 화면 구성 (MVP)

MVP의 모든 화면은 **좌측 탭 내비게이션 + 중앙 장면 + 우측 두루마리 알림 + 하단 상태/액션바**라는 하나의 틀(셸)을 공유한다. 틀 안의 "중앙 장면"만 탭에 따라 바뀐다. (아래 초안 이미지가 이 틀의 기준.)

```
┌───────────────────────────────────────────────────────────────────┐
│ [국호/군주]   [석 1,200] [엽전 3,500] [권위 65]  [날짜 900년 가을] [≡][⚙][X]│  ← 상단 바
├───┬───────────────────────────────────────────────────────┬───────┤
│ 1 │                                                         │ 민심불만│
│영지│                                                         │ 호족청원│  ← 우측
│개요│              중앙 장면 (탭에 따라 교체)                    │ 건설완료│    두루마리
│ 2 │                                                         │       │    알림
│호족│                                                         │       │
│관리│                                                         │       │
│ 3 │                                                         │       │
│경제│                                                         │       │
│농업│                                                         │       │
│ 4 │                                                         │       │
│군사│                                                         │       │
│사병│                                                         │       │
│ 5 │                                                         │       │
│외교│                                                         │       │
│책략│                                                         │       │
│ 6 │                                                         │       │
│병영│                                                         │       │
│징집│                                                         │       │
├───┴───────────────────────────────────────────────────────┴───────┤
│  현재 진행 중인 건설/모병 상태 (예: 저수지 정비 중 2/3턴 남음)          │  ← 하단
│        [빠른 액션 1]      [빠른 액션 2]      [빠른 액션 3]           │    상태/액션바
└───────────────────────────────────────────────────────────────────┘
```

이 틀과 별개로 **지도 화면**(아래 3.0)과 **전투 결과 팝업**(3.7)은 독립 화면/모달로 존재한다.

**책상 위 지도 (반복 요소)**: 중앙 장면 하단, 창문과 하단 상태바 사이에 책상에 펼쳐진 한반도 지도가 상시 걸쳐 보인다. 세력별 색 토큰으로 지역 소유권을 축약 표시 — 전체화면 지도(3.0)를 열지 않아도 정세를 가늠할 수 있는 장치. 모든 탭 화면에서 공통으로 보인다.

### 3.0 지도 화면 (MapScreen)
- 완산주 일대 지역을 노드(원)와 인접 선으로 표시한 그래프. 각 노드는 소속 세력 색으로 칠해짐.
- 내 지역 클릭 → 내정 화면(3.1)으로 진입. 미복속 호족 지역 클릭 → 요약 정보 + "출정"/"사신 파견" 단축 버튼.
- 상단에 같은 자원바 + 날짜, 하단에 "다음 턴" 버튼.
- MVP 지도 범위: 완산주 + 인접 호족 지역 8~10곳 (완주, 전주 인근 촌락들, 청주 방면 접경지 1~2곳 포함).

### 3.1 영지 개요 (탭 1 — 기본 진입 화면)
- 중앙: 영지를 창문 밖으로 내다보는 일러스트 장면 (성·전답·저자거리).
- 하단 상태바: 진행 중인 건설/프로젝트 + 남은 턴.
- 빠른 액션 3개: **영지 확대**(지도로 돌아가 인접 지역 선택), **징병 실행**(병영·징집 탭 단축), **세금 징수**(경제·농업 탭 단축).

좌측 탭은 화면이 하나씩 구체화될 때마다 와이어프레임에서 계속 늘어나는 중이다 (현재까지 확인된 순서: 영지 개요 → 호족·신하 → 주요 관직(내각) → 왕위 계승 및 후계자 → 신하 전체 관리 → 군사·사병 → …). MVP 셸이 이걸 전부 평평한 좌측 탭으로 둘지, 일부를 묶을지는 아직 미정이라 **§11 결정 필요 사항**에 남겨두고, 아래는 탭 순서보다 **내용** 기준으로 정리한다.

### 3.2 호족 판도 (탭: 호족·신하)
지도 + 인물 카드 2단 구성:
- **좌: 호족 판도 지도** — 완산주 일대를 충성도 기준 3색(초록 Loyal / 노랑 Neutral / 빨강 Rebel Risk)으로 칠한 지역 지도. 각 지역 위치에 해당 호족의 초상화 마커 + 이름표(지역+인물명)가 꽂혀 있다. 마커를 클릭해 호족을 선택.
  - 예시 인물(원본 기획서 세계관의 실존 호족을 샘플 데이터로 사용): 나주 호족 김총, 철원 호족 궁예, 상주 호족 아자개, 명주 호족 김순식 등. 완산주의 견훤은 MVP 시작 시점에는 **플레이어 본인**(말단 호족)이므로 지도에 등장하지 않음 — 2차 범위에서 다른 세력 플레이 시 등장.
- **우: 선택한 호족 상세 카드** — 초상화, 이름, 충성도 %(색상 라벨 동반: 예 "15% (Red)"), 보유 병력 수, **주요 불만**(충성도가 낮은 이유를 한 줄로 — 예: "중앙군 파견 반대") 텍스트.
- 하단 액션바(선택한 호족 대상): **정략결혼 제안**(권위 소비, 충성도 고정 + 이탈 불가 — 되돌릴 수 없음), **인질 요구**(충성도 상한↑ 대신 호족 반감 누적), **호족 회유**(엽전 소비, 충성도 +N, 반복 가능), **숙청 명령**(무력 제거 — 충성도 극히 낮고 반란 임박한 호족을 선제 토벌, 병력 손실 리스크 + 명분/권위 소비).
- 우측 알림 두루마리에 호족 관련 사건이 함께 뜬다 (예: "OO 호족의 조세 거부", "OO 호족의 혼인 동맹 제안", "OO 호족의 중립 유지").

### 3.3 주요 관직 (내각)
중앙 조정의 핵심 보직 3개를 카드로 나열:

| 관직 | 분야 | 효과 |
|---|---|---|
| 대상서 | 행정 총괄 | 내정 효율(생산/건설 속도) 보너스 |
| 대장군 | 군사 총괄 | 중앙군 훈련 속도 보너스 |
| 내사령 | 외교·책략 | 외교 성공률 보너스 |

- 각 카드: 임명자 초상화 + 이름 + 출신(호족 연고 또는 유학자 등 배경), 효과 수치, 충성도, **임명 변경** 버튼(미임명/공석도 가능 — 효과 없음).
- 우측 두루마리 "조정 칙령 및 보고": **정무 보고**(현재 임명의 영향을 서술형으로 알려줌 — 긍정 효과와 함께 "지나친 권력 집중을 경계해야 합니다" 같은 리스크 경고도 포함), **인사 제안**(예: "나주 호족 김총의 자제를 중앙 관직에 등용하여 결속을 다질 것을 권장" — 호족을 중앙으로 끌어들여 충성도를 관리하는 수단을 알려주는 훅. §3.2의 호족 충성도 시스템과 직접 연결).
- 하단 버튼: **전체 신하 명부**(§3.5로 이동), **파면 및 유배**(선택된 관직자 해임 + 처벌 — 충성도·권위에 영향, 해당 호족과의 관계 악화 리스크).
- 예시 인물(실존 고려 개국공신을 샘플 데이터로 사용): 박지윤(청주 호족, 내정 효율 +15% / 충성도 85%), 유금필(평주 호족, 중앙군 훈련 속도 +20%), 최응(신라 유학자, 외교 성공률 +25%).

### 3.4 왕위 계승 및 후계자 — **게임의 핵심 시스템**
원칙은 **장자 승계**지만, 고정이 아니라 **명분 점수(Legitimacy Score) 경쟁**으로 풀어낸다. 후계자 관리를 잘하는 것 자체가 게임의 묘미가 되도록 설계한다.

- **후계자 카드**: 왕자/대군마다 하나씩 — 초상화, 이름(+출생 순서: 장자/2황자 등), **지지도 %**(조정 파벌의 실제 지지 비율), **명분 점수**(장자 보너스 + 능력·공적 가감으로 산출되는 계승 서열의 실질 기준), 능력/기량 요약(무력·지력 등 특기), 지지 호족 목록.
  - 장자는 기본적으로 명분 점수에 **적통 장자 보너스**가 붙어 유리하게 시작한다.
  - 하지만 장자가 무능하거나 실정을 거듭하면 점수가 깎이고, 능력이 뛰어나거나 공적을 세운 차남·삼남은 점수가 오른다 — **가장 높은 명분 점수를 가진 쪽이 계승자**가 된다(장자 고정이 아님).
  - "지지도 %"는 명분 점수와는 별개로, 조정 신하·호족들이 실제로 누구를 지지하는지의 집계치. 명분 점수가 결과를 정하지만, 지지도가 낮은 채로 계승하면 뒤따르는 파벌 문제(아래)가 더 커진다.
- **카드 버튼**: 1후계자(현재 1위)는 **태자 책봉 확정**(공식화 — 명분 점수에 고정 보너스 추가), 그 외 후계자는 **후계자 지지 선언**(플레이어가 권위를 들여 특정 후계자를 공개 지지, 그의 지지도·명분 상승).
- **우측 두루마리 "조정 파벌 판도"**: 신하·호족들이 어느 후계자를 왜 지지하는지 묶어서 보여줌 (예: "군부 파벌 — 1후계자 전폭 지지, 국경 수비에 유리" / "문신 및 지방 호족 파벌 — 2후계자의 내정 능력을 높이 사며 정권 교체를 은근히 기대"). §3.3의 관직자·§3.5의 신하들이 자동으로 이 파벌에 속한다.
- **하단 액션**: **후계자 교육**(자원 소비, 대상 후계자의 능력·명분 점수를 서서히 올림), **폐위 및 유배**(후계자 자격 박탈 — 그 파벌의 반감 급증, 강경책).

**승계가 실제로 일어나면** (군주 사망/양위 — 2차 범위의 수명 시스템 또는 플레이어의 "양위" 선택으로 트리거):
1. 그 시점 **명분 점수 최고자**가 다음 군주가 되어 **왕실 금고(엽전 일부)와 중앙군을 그대로 물려받는다.**
2. 낙선한 후계자를 지지하던 파벌(신하·호족)을 **처분(파면·숙청)하려면 새 군주의 세력(중앙군 규모·권위)이 충분해야** 가능하다.
3. 세력이 부족하면 처분하지 못하고, 그 파벌은 조정 안에 **그대로 남아 정치를 시작**한다 — 정책에 반대하거나 충성도에 지속적으로 악영향을 준다.
4. 방치하면 그 파벌이 **다른 왕족(낙선 후계자 등)을 중심으로 결집**해 반란·내전으로 번질 수 있다.
5. 즉 승계 이후에도 플레이어는 §3.2(호족 회유/숙청)·§3.3(관직 임명)의 도구를 똑같이 써서 이 파벌들을 계속 "잘 연결"해 나가야 한다 — 왕위 계승은 한 번의 이벤트가 아니라 그 이후 조정 정치의 시작점이다.

**MVP 범위**: 완산주 한 주를 통일하는 MVP 플레이 길이 안에서는 계승 이벤트 자체가 실제로 발동되지 않을 수도 있다. 그래도 후계자 목록·명분 점수·지지도 계산과 태자 책봉/지지 선언/후계자 교육/폐위 같은 **상시 관리 UI는 MVP에 포함**해 플레이어가 처음부터 이 축을 신경 쓰게 만든다. 계승 발생 시의 파벌 처분/내전 로직은 §9 체크리스트에서 "뼈대만 MVP, 완전한 내전 AI는 2차 범위"로 구분한다.

### 3.5 전체 소속 신하 (명부)
관직 보유자(§3.3) + 지역에 태수·장수로 임명된 인물 + **문객**(아직 공식 직위가 없는 재야 인재 — 전란 중 투항·포로였다가 등용 가능해진 장수, 떠돌이 학자 등)까지 한 화면에서 필터로 넘나든다.
- 필터: 전체 / 관직자 / 일반 신하(지역 임명) / 문객. 정렬: 충성도·능력치·소속 파벌.
- 문객은 **초빙**(엽전/권위 소비)으로 관직(§3.3)이나 지역 임명으로 끌어올릴 수 있음 — 방치하면 다른 세력에 떠날 수도 있음(2차 범위). 원본 기획서 5장의 "포로 삼고초려 등용"이 승낙되면 이 풀에 합류한다.
- 모든 신하는 §3.4의 후계자 파벌에 (있다면) 소속돼 있으며, 여기서 재배치·해임하면 그 파벌 소속도 함께 정리된다.

### 3.6 경제·농업 (시설 관리)
참고로 받은 "시설관리" 레퍼런스는 다른 게임 화면(조선시대 소재, 육각 미니맵·실시간 UI)이라 우리 셸(상단 바·좌측 탭·우측 알림)과 크롬은 다르지만, **좌측에 자원+건축물 목록을 띄우는 내용 구성**은 그대로 가져온다:
- **좌측 패널(또는 중앙 장면 내 목록 영역): 자원 현황** — 자원별로 보유량과 이번 계절 생산율을 한 줄씩(아이콘 + 수치 + %). MVP는 석(쌀)·엽전이 핵심이고, 나무·철·비단 같은 가공 자원은 원본 기획서 5장의 "해상 무역"과 묶어 2차 범위로 둔다(§11).
- **건축물 목록** — 지역에 지은 시설(논/저수지 등)을 레벨 배지 + 다음 레벨 업그레이드 비용(자원 아이콘 조합)과 함께 세로로 나열, 스크롤 가능. 클릭하면 **업그레이드** 실행.
  - MVP 시설: **논(농업 개간)**, **저수지(수리시설)** — 둘 다 레벨업 시 석 생산량 증가. 2차 범위에서 대장간(철)·옹기마당(비단 가공) 등 가공 시설 추가.
- **세율 슬라이더**: 세율↑ = 엽전↑/충성도↓ 트레이드오프.
- 생산 미리보기 (이번 계절 예상 석/엽전 수입).
- 선택된 지역 정보 카드(지역명 등)는 하단 상태바와 겹치지 않게 §3의 공통 셸 영역을 그대로 쓴다.

### 3.7 군사·사병 — "병력 현황"
병력은 두 갈래로 나뉜다 (원본 기획서 4장 "호족 충성도와 신하 관리"를 구체화):
- **중앙군**: 플레이어가 직접 징병·훈련한 상비군. 정예병/특기병종별 보유·정원, 사기 상태 표시. 언제나 100% 동원 가능. 승계 시 새 군주에게 그대로 상속(§3.4).
- **호족 사병**: 복속시킨 호족이 자체적으로 보유한 사병. 목록에 호족 이름·충성도·보유 사병 수. **동원령**을 내리면 충성도에 비례해 동원 응하지만, 충성도가 낮으면 "동원 거부" — 호족 판도 탭에서 충성도를 먼저 올려야 함. 이 설계로 호족 관리와 군사 시스템이 직접 연결된다.
- 장수: 무력·지력·충성·출신 호족 연고·야심 성향, 임명 상태(태수/장수/재야). 부대 편성 시 장수를 지휘관으로 배치.
- 하단 액션바: **동원령 내리기**(호족 사병 소집 시도), **훈련 강화**(중앙군 사기/숙련 상승, 석 소비), **병과 편제 변경**(2차 범위 — MVP는 병종 1종이라 비활성).

### 3.8 외교·책략
- 인접 세력/호족과의 관계 상태.
- 액션: **정략결혼**(동맹·충성 강화), **위협**(복속 요구, 거부 시 명분 획득 후 공격 가능), **첩보**(상대 전력 확인 — 2차 범위).
- 포로로 잡은 적 장수 처리: **등용** 또는 **처형** 선택지 (원본 기획서 5장) — 등용하면 §3.5 문객 풀로.

### 3.9 병영·징집
- 사병 모집 큐 (석/엽전 소모 → 병력 생산, 소요 턴).
- MVP는 병종 1종(사병)만. 병종 세분화(창병/궁병/기병, 상성)는 2차 범위.

### 3.10 전투 결과 (팝업)
- 원정/침공이 해소되는 턴에 뜨는 모달: 아군·적군 병력, 장수 참여, 승패, 노획/손실 요약, 포로 처리 선택지로 연결.

| 9 | BattleSystem | 전투 결과 팝업 | 원정/침공 전투 해석 (병력 수 × 장수 보정 × 약간의 무작위) |

### 5.1 자원 (MVP)

| 자원 | 설명 | 주요 생산원 | 주요 소비처 |
|---|---|---|---|
| 석 (食) | 식량 | 농업 개간, 저수지 | 징병, 기근 방지 |
| 엽전 | 화폐 | 세금 징수 | 호족 회유, 건설, 징병 |
| 권위 | 명분·위신 | 턴마다 소량 자동 + 정복/이벤트 보상 | 작위 승격, 혼인 동맹, 위협(명분) |
| 병력 | 사병 수 (지역별 주둔) | 병영·징집 | 원정, 수비 |

### 5.2 호족 충성도
- 충성도 0~100. 낮으면 세금 체납·이탈 확률 상승 (원본 기획서 4장 "반란 리스크").
- 세율이 높을수록, 방치(아무 액션 없이 지나간 턴 수)할수록 충성도 하락.
- 회유 1회 = 엽전 소비, 충성도 +N. 인질 = 충성도 상한 확장이지만 "반감" 플래그(미래 반란 시 가중치). 혼인 동맹 = 권위 소비, 충성도 고정(이탈 불가) — 대신 되돌릴 수 없음.

### 5.3 신하·관직 (§3.3, §3.5)
- 신하는 세 상태 중 하나를 가진다: **관직자**(대상서/대장군/내사령 중 하나에 임명, 왕국 전체에 effect 적용), **일반 신하**(지역 태수·원정 지휘관 등으로 임명, 해당 지역/부대에만 effect 적용), **문객**(미소속 — effect 없음, 초빙 전까지 대기).
- 관직 3종은 각각 분야별 effect 하나씩 제공(§3.3 표). 공석이면 효과 없음. 교체(임명 변경)는 즉시 적용되지만 전임자의 소속 호족과의 관계에 영향을 줄 수 있음(2차 범위에서 세분화).
- 호족을 중앙 관직·신하로 끌어들이는 것 자체가 **충성도 관리 수단**이다 — "인사 제안" 이벤트(§3.3)가 이를 플레이어에게 안내.
- 파면 및 유배는 즉시 공석화 + 해당 인물 충성도 초기화(다시 등용하려면 문객부터) + 출신 호족 충성도 하락 리스크.
- 모든 신하는 §5.4의 후계자 파벌에 (있다면) 소속되어, 신하 관리 액션이 승계 정치에도 영향을 준다.

### 5.4 왕위 계승 (§3.4) — 명분 점수제
- **명분 점수** = 출생 순서 보너스(장자 기본값 가장 높음) + 능력·공적 누적 가감(전투 승리·내정 성과 → 가산, 실정·무능 → 감산) + 플레이어 액션 보정(태자 책봉 확정 = 고정 보너스, 후계자 지지 선언 = 소폭 가산, 후계자 교육 = 서서히 가산). **장자 고정이 아니라 매 턴 재계산**되는 값 — 유능한 차남이 역전할 수 있다.
- **지지도 %** = 명분 점수와 별개로, 조정 신하·호족 각자가 자신의 성향(능력 중시/적통 중시/인맥 등)에 따라 어느 후계자를 지지하는지 집계한 비율. MVP는 "관직자·주요 신하 1인 1표, 영향력(관직 보유 여부)으로 가중"으로 단순화. §5.3의 관직 임명이 이 집계에 직접 반영된다.
- **파벌**: 같은 후계자를 지지하는 신하·호족 묶음. 우측 "조정 파벌 판도"에 파벌 단위로 노출(§3.4).
- **승계 처리** (2차 범위에서 완전 구현, MVP는 데이터 구조·상시 관리 UI만):
  1. 군주 교체 시점의 **명분 점수 최고 후계자**가 계승 → 왕실 금고(엽전)와 중앙군을 그대로 상속.
  2. 신군주의 **세력**(중앙군 규모 또는 권위)이 임계치 이상이면 낙선 후계자의 파벌을 처분(파면/숙청) 가능.
  3. 세력 미달 시 파벌 존속 → "조정 정치" 상태(정책 반대, 충성도 지속 악화)로 전환.
  4. 방치하면 파벌이 다른 왕족을 옹립해 결집 → 반란/내전 리스크로 발전(완전한 내전 AI는 2차 범위, MVP는 파벌 불만도가 임계치를 넘으면 지역 이탈/반란 이벤트로 단순화).

### 5.5 전투 (MVP 단순화)
- 원본 기획서 5장의 "평야 기병전/산성 공성전/하천 수전" 세분화는 2차 범위.
- MVP 공식: `아군 전투력 = 병력 수 × (1 + 지휘 장수 무력/100) × 지형 보정`, 상대도 동일 계산 후 비율로 승패·손실 결정 + 약간의 무작위성(시드 저장 → 재현 가능, RuleTheKingdom의 BattleSimulator 패턴 재사용).
- 패전한 적 장수는 포로로 잡힐 수 있음 → 등용/처형 선택지.

## 7. 데이터 구조 설계 (ScriptableObject)

`RuleTheKingdom`과 같은 데이터 주도 방식을 쓰되, 턴제 전략에 맞게 구성한다.

```
FactionDef      세력 하나의 정의 (id, 국호, 군주명, 색상, 세력 성향 보너스)
ProvinceDef     지역 하나의 설계도 (id, 표시이름, 인접 지역 id 목록, 지도 좌표,
                시작 소속 세력, 기초 농업/수리시설/인구)
RetainerDef     신하(장수·문관·왕자 통칭) 하나의 정의 (이름, 무력, 지력, 매력, 출신 지역 연고,
                야심 성향, 초상화) — 호족 출신 여부는 originHojokId로 표시해 §3.3 "인사 제안"
                같은 호족-신하 연결 훅에 쓴다. isHeir + birthOrder로 군주의 자녀(후계자 후보)도
                같은 정의를 재사용한다 (능력치가 이미 있으므로 명분 점수 계산에 그대로 쓸 수 있음)
OfficeDef       주요 관직 정의 (대상서/대장군/내사령) — id, 명칭, 분야(행정/군사/외교),
                effect 종류 + 수치
ResourceDef     석/엽전/권위 등 자원 정의 (id, 표시이름, 아이콘)  — RuleTheKingdom과 동일 패턴
GameDatabase    위 정의들의 목록 + MVP 밸런스 수치 (세율 상한, 충성도 임계치, 전투 상수,
                적통 장자 명분 보너스 등)
```

런타임 상태(세이브 대상)는 별도 POCO로:

```
ProvinceState   { provinceId, ownerFactionId, 농업Lv, 수리시설Lv, 세율, 주둔병력, 충성도, 건설진행 }
FactionState    { factionId, 석, 엽전, 권위, 보유 신하 id 목록, 현재 군주 retainerId }
RetainerState   { retainerId, 소속 factionId, status(관직자/일반신하/문객/포로),
                officeId(관직자일 때), assignedProvinceId(지역 임명일 때), 충성도 }
HeirState       { retainerId(RetainerState와 연결), 명분점수, 지지도, 태자책봉여부,
                지지 신하/호족 id 목록(파벌) }
```

## 8. 아트 / 사운드 — 결정 필요

- 제시된 초안 이미지는 **수묵 채색 일러스트** 톤 (한옥 창틀, 단청, 회화풍 영지 전경). `RuleTheKingdom`의 32px 픽셀아트·PixelLab 파이프라인과는 다른 결이라 **이 프로젝트는 별도 아트 파이프라인이 필요하다** (§11 결정 필요 사항 참고).
- MVP 단계에서는 실제 일러스트가 없어도 진행 가능하도록, 중앙 장면은 placeholder(단색 배경 + 설명 텍스트)로 먼저 구성하고 레이아웃만 최종 구도에 맞춘다.
- 폰트: `RuleTheKingdom`과 동일하게 갈무리(Galmuri) 재사용 (한글 도트 폰트가 이 그림체와 어울리는지는 재검토 가능).

## 9. MVP 범위 체크리스트

- [ ] 지도 화면: 완산주 일대 8~10개 지역 노드 + 인접 그래프, 소속 세력 색
- [ ] 공통 셸 UI (상단 바·좌측 탭·우측 알림·하단 상태바·책상 지도) + §3의 화면들(영지 개요/호족 판도/주요 관직/왕위 계승/전체 신하/경제·농업/군사·사병/외교·책략/병영·징집)
- [ ] 계절 턴 진행 (생산 정산, 건설/모병/원정 진행, "다음 턴" 버튼)
- [ ] 자원 4종: 석·엽전·권위·병력
- [ ] 호족 충성도 + 회유/인질/혼인동맹/숙청
- [ ] 관직 3종(대상서/대장군/내사령) 임명·파면 + 왕국 전체 effect 적용
- [ ] 신하 데이터 + 임명/재배치 (등용은 포로 처리·문객 초빙에서 트리거)
- [ ] 후계자 명분 점수·지지도 계산 + 태자 책봉/지지 선언/교육/폐위 UI (승계 발생 시 파벌 처분/내전은 뼈대만 — §5.4)
- [ ] 자원 현황 + 건축물(논/저수지) 레벨·업그레이드 비용 목록 (§3.6)
- [ ] 단순 전투 해석 (원정/침공) + 결과 팝업 + 포로 등용/처형
- [ ] 세율 조정 + 농업/수리시설 업그레이드
- [ ] 완산주 통일 시 MVP 승리 처리
- [ ] 저장/불러오기 (JSON)

2차 범위(기획서 원안의 나머지 + 화면 반영 중 늘어난 항목): 태봉·신라 본격 참전, 병종 세분화(창병/궁병/기병 상성), 지형별 전투(평야/산성/수전), 해상 무역(나무/철/비단 가공 시설), 도(道) 단위 이후 전국 통일, 완전한 승계 후 내전·파벌 AI, 문객 이탈.

## 10. 기술 설계 (Unity)

- **데이터 주도**: 자원·세력·지역·장수는 ScriptableObject로 정의, `GameDatabase`에 등록 (§7).
- **턴 시뮬레이션**: 실시간이 아니라 "다음 턴" 버튼으로 진행하는 명시적 틱 — `TurnManager.AdvanceSeason()` 하나가 모든 시스템의 턴 훅을 순서대로 호출.
- **저장**: `JsonUtility` → `persistentDataPath/save.json` (RuleTheKingdom과 동일 패턴). 실시간 게임이 아니므로 자동저장은 턴 종료 시점 + 수동 저장.
- **UI**: UI Toolkit, 셸(상단 바/좌측 탭/우측 알림/하단 상태바)과 탭별 콘텐츠를 분리해 구성. 기준 해상도 1920×1080 (초안 이미지 비율 기준, RuleTheKingdom의 1280×720보다 넓음).
- **맵**: 격자가 아니라 지역 노드 그래프 (좌표 + 인접 리스트). Tilemap/Grid 불필요.
- **폴더 구조**

```
Assets/_Project/
  Scripts/Data      정의 (ScriptableObject): FactionDef, ProvinceDef, RetainerDef, OfficeDef, ResourceDef, GameDatabase
  Scripts/Core      GameManager, TurnManager, 세이브
  Scripts/Systems   EconomySystem, LoyaltySystem, RetainerSystem, SuccessionSystem, MilitarySystem, DiplomacySystem, BattleSystem, EventSystem
  Scripts/UI        셸 + 탭별 화면 (UI Toolkit)
  Scripts/Editor    샘플 데이터 세팅 (KingdomSetup과 동일한 역할)
  UI/               USS 스타일시트 (한옥/단청 톤)
  Fonts/            갈무리
  Art/Sprites/      실제 일러스트 (파이프라인 결정 후)
  Data/ Scenes/ Prefabs/   (에디터 메뉴가 생성)
```

## 11. 결정이 필요한 사항 (Open Questions)

1. **아트 파이프라인** — 초안처럼 회화풍 일러스트를 어떻게 양산할지 (수작업/커미션/다른 AI 생성 도구). PixelLab은 픽셀아트 전용이라 이 톤에는 안 맞음.
2. **지도 화면의 시각적 형태** — 노드 그래프(점+선)로 충분한지, 아니면 초안과 같은 삽화풍 지도가 필요한지.
3. **AI 세력의 적극성** — MVP에서 AI가 플레이어를 역공격할 수 있게 할지, 아니면 수세적으로만 둘지.
4. **승리 후 흐름** — 완산주 통일 후 바로 2단계(도 단위)로 이어갈지, MVP는 엔딩 화면에서 끝낼지.
5. **세이브 슬롯** — 1개만 지원할지 다중 세이브를 지원할지.
6. **좌측 탭 깊이** — 와이어프레임은 호족 판도/주요 관직/왕위 계승/전체 신하 등을 전부 평평한 좌측 탭으로 그리고 있어 탭이 계속 늘어나는 중이다. 실제 셸에서 전부 독립 탭으로 둘지, 비슷한 화면끼리 묶어 상위 탭 + 서브탭으로 압축할지 정해야 한다 (탭이 9개를 넘어가면 스크롤이든 그룹핑이든 필요).
7. **계승 트리거 방식** — 군주 수명/사망 시스템을 만들지(현실적이지만 MVP엔 무거움), 아니면 플레이어가 "양위"를 선언하는 버튼으로 MVP에서는 단순화할지.
8. **시설관리 레퍼런스의 자원 확장** — 나무·철·비단을 MVP에 바로 추가할지, 아니면 §9처럼 2차 범위로 미루고 MVP는 석·엽전·권위·병력 4종만 유지할지.
