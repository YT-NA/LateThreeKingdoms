## 1. 내일 아침 할 일 (다른 컴퓨터에서, 순서대로)

1. **그 컴퓨터에 Unity가 있는지 확인**
   - 시작 메뉴에서 "Unity Hub"를 찾아 연다 → 왼쪽 **설치(Installs)** → **6000으로 시작하는 버전(Unity 6)** 이 있으면 OK.
   - 없으면: unity.com 에서 Unity Hub 설치 → Hub에서 **Install Editor → Unity 6 (6000.x)** 설치. (지난번 컴퓨터는 6000.6.5f1)
2. **게임 받기**
   - 브라우저에서 `https://github.com/YT-NA/LateThreeKingdoms` → 초록색 **Code** 버튼 → **Download ZIP**
   - 받은 ZIP을 우클릭 → **압축 풀기**
3. **실행 파일 만들기**
   - 압축 푼 폴더 안의 **`후삼국_만들기.bat`** 를 더블클릭 → 검은 창이 뜨고 5~15분 걸린다 (처음엔 오래 걸림). 창을 닫지 말 것.
   - 끝나면 게임이 자동으로 켜진다. 실행 파일 위치: **바탕 화면\후삼국시대\v2\후삼국통일.exe**
     (예전 컴퓨터처럼 `C:\Users\sjart\OneDrive\바탕 화면`이 있으면 그곳, 없으면 그 컴퓨터의 바탕 화면)
4. **안 되면**: 같은 폴더에 생긴 **`build_husamguk.log`** 를 메모장으로 열어 내용을 Claude에게 붙여넣는다. 추측으로 고치지 않고 로그를 보고 고친다.
5. **로컬 Claude Code로 이어 갈 때**: 압축 푼 폴더에서 Claude Code를 열고 "docs/HANDOFF.md 읽고 이어서 해줘"라고 하면 된다.

| 문제 (v1 피드백) | v2에서 |
|---|---|

| 진행도가 없음 | **판도 지도**(8고을, 길 연결선, 우리 땅=붉은색, 호족은 충성도에 따라 갈색→초록, 손 닿는 고을은 금색 테두리). **계절 보고**(수확·군량·공사 완료·귀부·습격…)와 **연대기** 탭. 고을 등급 승격(촌→현→군…) 축하 사건. |
| 탭 대부분이 "다음 작업" | 빈 탭 제거. 영지(개요/경제·농업), 호족·신하(호족 판도/신하), 군사(병영·징집/출진), 연대기 — 전부 실제로 동작. |
| 그림이 하나도 안 보임 | 원인 수정: 그림이 처음 임포트될 때 스프라이트가 아닌 일반 텍스처로 찍혀 연결이 안 됐다. 이제 샘플 세팅/빌드 때 자동으로 바로잡는다. 초상화·고을 그림·병종·자원 아이콘이 화면에 쓰인다. |
| 선택의 재미가 없음 | 시작 인물 2명: **김억**(이서, 회유형 — 매력↑) / **김총**(고부, 무력형 — 통솔↑). 군주 매력=회유 효과, 통솔=전투력. |

### 바뀐 규칙 (게임 시스템)
- **회유 → 귀부**: 맞닿은 호족의 충성이 80이 되면 계절이 바뀔 때 스스로 귀부하고 **사병도 함께** 들어온다. 세력이 커질수록 회유·사성 비용이 오른다.
- **토벌의 딜레마**: 칼로 빼앗으면 빠르지만 다른 호족 충성 -10(두려움). 빼앗은 고을은 충성 30으로 시작 → 민심을 달랠 때까지 수확이 적고 **장정이 모이지 않는다**(충성 50 미만 절반, 35 미만 0). 충성 30 미만 호족은 국경을 습격해 곡식을 약탈한다.
- **민심**: 세율이 목표 충성을 정한다(목표 = 70 − 세율%). 계절마다 3씩 그쪽으로 움직인다. 25 미만이면 민란 사건.
- **계절**: 가을 수확 ×1.6, 겨울 ×0.5. 병사는 계절마다 군량을 먹고, 바닥나면 병사가 달아난다.
- **장터**: 엽전 20 → 석 20 / 석 20 → 엽전 10.
- **전투**: 상성(창>기>궁>창)이 상대 구성 비율대로 반영(예전엔 천적이 한 명만 섞여도 통째로 불리해지는 버그). 성곽 보정(촌 ×1.15 … 주 ×1.6). 완산주는 정예 창·궁·기병 105명으로 시작해 계속 늘어나는 최종 관문 — 회유 불가.
- **저장**: 매 계절 자동 저장(실행 파일 옆 `save.json`), 시작 화면에 "이어하기".

## 3. 검증한 것 / 못 한 것 (솔직하게)

**검증함**
- 클라우드에 Unity가 없어서, Unity API 스텁을 만들어 **모든 스크립트(Data/Core/UI/Editor)를 컴파일 검사**했다 → 오류 0. (`tools/headless/README.md`)
- **게임 로직을 실제로 12판 자동 플레이**(인물 2 × 회유/토벌 × 시드 3): 12판 모두 승리, 예외·진행 막힘·저장/불러오기 불일치 없음. 걸린 시간: 김총 토벌 ≈15계절, 김억 토벌 15~19, 김총 회유 23~27, 김억 회유 31~51.
- 이 시뮬레이션으로 실제 버그/밸런스 문제를 여럿 잡았다: 견훤군이 사신 거절 바로 다음 계절에 쳐들어오던 버그, 목표 하나에 막혀 목표 전체가 멈추던 구조, 엽전이 수천씩 남아도는 문제(→장터), 상성 계산 버그, 승격 축하 창이 매 계절 뜨던 문제, 첫 귀부가 2계절 만에 되던 문제 등.
- 저장소 분리 후 빌드 스크립트가 결과 파일을 저장소 **바깥**에 써서 `.bat`가 "실패"라고 하던 버그도 고쳤다.

**못 함 (Unity에서만 확인 가능 — 내일 플레이테스트로 봐 주세요)**
- 실제 Unity 컴파일 (스텁 검사는 통과했지만 스텁은 진짜 Unity가 아니다)
- 화면 배치: 글자 넘침, 카드 크기, 대화창 위치, 지도 노드 겹침, 색감
- 지도의 길 연결선(painter2D) 실제 표시
- 그림 임포트 수정이 실제로 37장을 띄우는지

**플레이테스트 때 특히 봐 줄 것**
- [ ] 시작 화면에 초상화가 보이는가
- [ ] 첫 사건(난세의 첫걸음)이 뜨고 선택이 되는가
- [ ] 오른쪽 책사 조언을 따라가면 할 일이 이어지는가
- [ ] 지도 노드를 누르면 맞는 화면으로 가는가
- [ ] 회유를 거듭해 호족이 귀부하는가 (다음 계절)
- [ ] 글자가 잘리거나 겹치는 곳
- [ ] "한 턴만 더" 느낌이 드는가, 지루한 구간은 어디인가

## 4. 결정이 필요한 사항 (질문) — 답 주시면 반영합니다

각 질문에 **지금 기본으로 해 둔 것**을 적었다. 답이 없으면 기본안대로 간다.

1. **토벌이 회유보다 2배쯤 빠르다** (토벌 ≈15~19계절, 회유 ≈23~51계절). 의도한 균형인가? → 기본안: 유지(토벌=빠르지만 위험, 회유=느리지만 안정). 회유를 더 매력적으로 하려면 "귀부한 고을은 바로 승격" 같은 보상을 추가할 수 있다.
2. **한 판 길이**: 지금 5~12년(15~51계절). 원하는 길이는? → 기본안: 유지.
3. **실존 인물 배치**: 김총은 실제로는 순천 호족(견훤 휘하), 책사 최응은 황주 출신 궁예·왕건의 신하인데 이번 시나리오에선 호남 호족 가문에 넣었다. "역사 재현이 아니어도 된다"는 방향에 따라 둔 것. 괜찮은가, 가상 인물로 바꿀까? → 기본안: 유지.
4. **사건 대사 톤**: 사극체(…하십시오 / …지요). 더 무겁게(…하옵니다), 더 가볍게? → 기본안: 유지.
5. **자유 시나리오 vs 캠페인**: 지금 900년 완산주 시나리오는 캠페인 3장(후백제→신라→고려)과 별개인 "자유 시나리오"로 두고, 캠페인은 장 단위로 따로 만든다. → 기본안: 이대로.
6. **글꼴**: 갈무리(픽셀 글꼴) 파일은 있는데 화면은 아직 기본 글꼴. 갈무리로 바꾸면 레트로 느낌↑, 작은 글씨 가독성↓. → 기본안: 기본 글꼴 유지, 원하시면 교체.
7. **저장 슬롯**: 매 계절 자동 저장 1칸. 수동 저장/여러 칸이 필요한가? → 기본안: 1칸 유지.
8. **다음에 가장 먼저 만들 것**: (가) 전투 장면 연출 (나) 인재 영입 → 주요 관직 임명 (다) 혼사·자식 교육 (라) 캠페인 1장(후백제 15막) 스크립트화 (마) 사운드. → 기본안: 플레이테스트 피드백 반영 후 (나).
